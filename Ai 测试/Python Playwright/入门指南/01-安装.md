## 简介

Playwright 专为满足端到端测试的需求而创建。Playwright 支持所有现代渲染引擎，包括 Chromium、WebKit 和 Firefox。在 Windows、Linux 和 macOS 上进行测试，本地或在 CI 上，无头或有头模式并带有原生移动设备仿真。

可以将 [Playwright 库](https://playwright.cn/python/docs/library)用作通用浏览器自动化工具，它为同步和异步 Python 提供了一组强大的 API 来自动化 Web 应用程序。

本简介介绍了 Playwright Pytest 插件，这是编写端到端测试的推荐方法。

**您将学到**

- [如何安装 Playwright Pytest](https://playwright.cn/python/docs/intro#installing-playwright-pytest)
- [如何运行示例测试](https://playwright.cn/python/docs/intro#running-the-example-test)

## 安装 Playwright Pytest

Playwright 建议使用官方的 [Playwright Pytest 插件](https://playwright.cn/python/docs/test-runners)来编写端到端测试。它提供了上下文隔离功能，开箱即可在多种浏览器配置上运行测试。

首先安装 Playwright 并运行示例测试，以亲身体验其效果。

安装 [Pytest 插件](https://pypi.ac.cn/project/pytest-playwright/)

- Pip
- Poetry
- uv

```bash
pip install pytest-playwright
```

安装所需的浏览器

```bash
playwright install
```

## 添加示例测试

在当前工作目录或子目录中创建一个遵循 `test_` 前缀约定的文件，例如 `test_example.py`，并将以下代码放入其中。请确保您的测试函数名称也遵循 `test_` 前缀约定。

test_example.py

```py
import re

from playwright.sync_api import Page, expect



def test_has_title(page: Page):

    page.goto("https://playwright.cn/")



    # Expect a title "to contain" a substring.

    expect(page).to_have_title(re.compile("Playwright"))



def test_get_started_link(page: Page):

    page.goto("https://playwright.cn/")



    # Click the get started link.

    page.get_by_role("link", name="Get started").click()



    # Expects page to have a heading with the name of Installation.

    expect(page.get_by_role("heading", name="Installation")).to_be_visible()
```

## 运行示例测试

默认情况下，测试将在 chromium 上运行。这可以通过 [CLI 选项](https://playwright.cn/python/docs/running-tests)进行配置。测试以无头模式运行，这意味着在运行测试时不会打开浏览器界面。测试结果和测试日志将显示在终端中。

```bash
pytest
```
