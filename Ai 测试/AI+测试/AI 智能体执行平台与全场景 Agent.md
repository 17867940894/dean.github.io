## 二、AI 智能体（Agent）自动化测试执行平台

AI 智能体自动化测试执行平台是测试领域从“自动化”向“自主化”跨越的核心产物。它不仅仅是运行代码的容器，更是拥有“大脑”的测试执行端。

**AI 智能体（Agent）= LLM（大模型、大脑）+ Memory（记忆）+ Tool（工具）+ Planning（规划）**

### 2.1 定义

AI 智能体自动化测试执行平台是一种基于大语言模型（LLM）和多模态视觉模型（VLM）的集成环境。它将传统的测试驱动（如 Playwright/Selenium）与 AI 的推理能力结合，形成一个能够**感知（Perceive）** 、**思考（Think）** 并**行动（Act）** 的闭环系统。

**核心逻辑**：

1. **感知**：通过 DOM 树解析或 OCR/视觉识别，理解当前页面状态
2. **推理**：根据人类下达的模糊指令（如“购买最便宜的手机”），拆解成具体的点击、输入步骤
3. **执行**：驱动浏览器完成操作，并根据反馈实时纠错（如处理意外弹窗）

### 2.2 核心特征：与传统平台的区别

| 特性     | 传统自动化平台                 | AI 智能体执行平台            |
| -------- | ------------------------------ | ---------------------------- |
| 驱动源   | 预编写的代码脚本（Code-based） | 自然语言意图（Intent-based） |
| 定位机制 | 静态 Selector（ID/XPath）      | 动态语义与视觉特征           |
| 容错性   | 脆弱（UI 变动即报错）          | 极强（具备自愈与绕障能力）   |
| 测试路径 | 固定且单一                     | 自主探索与非线性遍历         |
| 价值核心 | 验证已知功能的正确性           | 发现未知路径下的逻辑漏洞     |

### 2.3 平台分类

目前的“平台”分为两类：**原生 Agent 平台**（全新架构）和**传统大厂升级版**（集成 AI 能力）。

| 势力类别                            | 行业定位   | 核心逻辑                                                     | 核心优势                                               |
| ----------------------------------- | ---------- | ------------------------------------------------------------ | ------------------------------------------------------ |
| **原生 Agent 平台（AI-Native）**    | 未来的主力 | 意图驱动：完全脱离脚本，Agent 实时观察 UI 并动态生成操作路径 | 零维护：UI 怎么改都不怕；自适应：能处理非线性逻辑      |
| **传统大厂升级版（AI-Integrated）** | 当下的饭碗 | 脚本 + AI 补丁：在 Playwright 等传统脚本上增加 AI 自愈和 NLP 生成能力 | 稳健性：符合企业合规要求；确定性：执行结果 100% 可预测 |

### 3.1 核心测试特性

| 特性                                 | 说明                                                         |
| ------------------------------------ | ------------------------------------------------------------ |
| **语义化断言（Semantic Assertion）** | 不需要写复杂的 `expect(locator).to_be_visible()` 或 `assert()`。可直接下达意图：“检查购物车里的商品价格是否与搜索页一致”，AI 会自主进行数据比对 |
| **视觉自愈（Visual Self-healing）**  | 传统平台最怕 UI 改版。Skyvern 通过多模态视觉（Vision）识别元素，即便前端代码重构，只要“长得像按钮”，测试就不会中断 |
| **黑盒路径探索**                     | 给定一个模糊目标（如“尝试在不登录的情况下购买商品”），它会自主寻找绕过登录的路径 |

### 3.2 Skyvern 与传统自动化平台对比

| 维度     | 传统自动化平台（如 Selenium/Playwright） | Skyvern（AI Agent 平台）           |
| -------- | ---------------------------------------- | ---------------------------------- |
| 驱动核心 | 确定性的脚本逻辑（If/Else）              | 不确定性的推理链（Thought/Action） |
| 定位方式 | DOM 元素（ID/XPath）                     | 视觉特征 + 语义上下文              |
| 维护成本 | 极高（随代码变动而崩溃）                 | 极低（随业务意图而变动）           |
| 测试范围 | 预设路径的回归测试                       | 未知路径的探索测试                 |
| 报错分析 | 抛出代码堆栈错误                         | 提供推理日志（解释为什么没点成功） |

## 四、全场景 AI 智能体

### 4.1 定义

#### 什么是全场景 AI 智能体

**全场景 AI 智能体（AI Agent）** 是以大模型为“大脑”，集成感知、记忆、规划、工具调用、自主执行、反馈优化的完整自治系统。核心是目标驱动、自主闭环、跨场景端到端完成复杂任务。简单说：你给目标，它自己拆步骤、找工具、动手干、干到完，全程少干预。

**核心特征（全场景能力）** ：

| 特征                 | 说明                                                 |
| -------------------- | ---------------------------------------------------- |
| **目标导向**         | 不只是“你问我答”，而是围绕目标自主推进               |
| **任务拆解**         | 复杂工作自动拆成多步骤、按序执行                     |
| **工具调用（手脚）** | 能读文件、用浏览器、操作软件、调 API、控设备         |
| **持久记忆**         | 记住偏好、历史、上下文，长期连贯协作                 |
| **自主闭环**         | 思考→执行→检查→修正→再执行，直到完成                 |
| **跨场景覆盖**       | 办公、开发、测试、数据分析、自动化、RPA 等全领域适配 |

#### 对比普通 AI 的核心差异

| 对比维度 | 普通 AI（豆包、元宝等）                        | 全场景智能体                                          |
| -------- | ---------------------------------------------- | ----------------------------------------------------- |
| 定位     | 被动输出内容（文案、回答、代码），是“语言专家” | 主动完成任务（规划+执行+交付），是“数字员工/全能助理” |
| 交互方式 | 被动响应、单次交互                             | 主动推进、持续闭环                                    |
| 输出类型 | 只输出不执行                                   | 执行并交付结果                                        |
| 记忆能力 | 无记忆或有限                                   | 持久记忆、长期连贯                                    |
| 工具集成 | 无工具或有限                                   | 丰富的工具调用能力                                    |

## 六、OpenClaw — Personal AI Assistant

### 6.1 安装

**系统要求**：

- Node.js ≥ 22.x（官方硬性要求，一键脚本会自动安装）
- 内存 ≥ 2GB（推荐 4GB+）
- 系统：macOS 12+、Windows 10/11、Linux（Ubuntu/Debian/Fedora）、WSL2（Windows 推荐）

#### （1）macOS / Linux / WSL2

```bash
# 一键安装（含 Node 检测+安装+新手引导）
curl -fsSL https://openclaw.ai/install.sh | bash

# 仅安装二进制，跳过新手引导（进阶）
curl -fsSL https://openclaw.ai/install.sh | bash -s -- --no-onboard
```

#### （2）Windows（PowerShell 管理员模式）

1. 以管理员身份打开 PowerShell（Win+X → 选择“Windows PowerShell（管理员）”）
2. 执行：

```powershell
# 官方脚本
iwr -useb https://openclaw.ai/install.ps1 | iex

# 国内镜像（备用）
iwr -useb https://clawd.org.cn/install.ps1 | iex
```

1. 若提示执行策略报错，先运行：

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

#### （3）安装验证

```bash
# 验证版本
openclaw --version

# 检查环境
openclaw doctor

# 启动服务（默认端口 7979）
openclaw start
```

访问 `http://localhost:7979` 确认服务正常。
