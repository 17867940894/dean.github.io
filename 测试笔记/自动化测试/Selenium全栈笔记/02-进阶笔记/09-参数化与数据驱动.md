# 参数化与数据驱动

> [!info] 本节目标
> 掌握 pytest 参数化（`@pytest.mark.parametrize`）、CSV/Excel/YAML 数据驱动的完整方案，实现"一套代码跑多组数据"。

相关笔记：[[02-PO模式]]、[[08-并发测试]]、实战项目 `utils/excel_reader.py`

## 一、参数化 vs 数据驱动

| 概念 | 含义 | 实现方式 |
| --- | --- | --- |
| **参数化** | 同一用例用不同输入跑多次 | `@pytest.mark.parametrize` |
| **数据驱动** | 测试数据从外部文件加载 | 读 CSV/Excel/YAML/JSON |

实际项目中两者结合：**外部文件存数据 → 加载成列表 → `parametrize` 跑用例**。

## 二、pytest 参数化

### 2.1 基本用法

```python
import pytest

@pytest.mark.parametrize('username, password, expected', [
    ('admin', 'Admin@123', 'success'),
    ('admin', 'wrongpass', 'fail'),
    ('', '123456', 'fail'),
    ('guest', 'Guest@123', 'success'),
])
def test_login(username, password, expected):
    login_page.load().login(username, password)
    if expected == 'success':
        assert home.is_loaded()
    else:
        assert '错误' in login_page.get_error_message()
```

### 2.2 参数化 ID

默认用例名是 `test_login[admin-Admin@123-success]`，可读性差。可自定义 ID：

```python
@pytest.mark.parametrize(
    'username, password, expected',
    [
        ('admin', 'Admin@123', 'success'),
        ('admin', 'wrongpass', 'fail'),
    ],
    ids=['正常登录', '密码错误']
)
def test_login(username, password, expected):
    ...
# 用例名: test_login[正常登录], test_login[密码错误]
```

### 2.3 用函数生成参数

```python
def load_login_data():
    """从外部加载数据"""
    return [
        ('admin', 'Admin@123', 'success'),
        ('admin', 'wrong', 'fail'),
    ]

@pytest.mark.parametrize(
    'username, password, expected',
    load_login_data()
)
def test_login(username, password, expected):
    ...
```

## 三、CSV 数据驱动

### 3.1 CSV 文件示例

```csv
username,password,expected
admin,Admin@123,success
admin,wrongpass,fail
,123456,fail
guest,Guest@123,success
```

### 3.2 读取 CSV

```python
import csv
import os

def load_csv(file_path):
    """
    读取 CSV 文件，返回字典列表
    :return: [{'username': 'admin', 'password': 'Admin@123', 'expected': 'success'}, ...]
    """
    data = []
    with open(file_path, 'r', encoding='utf-8-sig') as f:  # utf-8-sig 兼容 Excel 编辑
        reader = csv.DictReader(f)
        for row in reader:
            data.append(dict(row))
    return data

# 使用
data = load_csv('data/login_data.csv')
```

### 3.3 在用例中使用

```python
@pytest.mark.parametrize(
    'case',
    load_csv('data/login_data.csv'),
    ids=[c['username'] or 'empty' for c in load_csv('data/login_data.csv')]
)
def test_login(case):
    login_page.load().login(case['username'], case['password'])
    if case['expected'] == 'success':
        assert home.is_loaded()
    else:
        assert '错误' in login_page.get_error_message()
```

## 四、Excel 数据驱动（最常用）

### 4.1 安装

```bash
pip install openpyxl   # 处理 .xlsx
# 或
pip install xlrd       # 处理 .xls（旧格式）
```

### 4.2 Excel 文件结构

`data/login_data.xlsx`：

| username | password | expected | description |
| --- | --- | --- | --- |
| admin | Admin@123 | success | 正常登录 |
| admin | wrongpass | fail | 密码错误 |
| guest | Guest@123 | success | 访客登录 |

### 4.3 ExcelReader 工具类

```python
"""
Excel 读取工具类
位置：utils/excel_reader.py
"""
import openpyxl
import os


class ExcelReader:

    def __init__(self, file_path, sheet_name=None):
        """
        :param file_path: Excel 文件路径
        :param sheet_name: sheet 名称，默认第一个
        """
        self.file_path = file_path
        self.workbook = openpyxl.load_workbook(file_path, data_only=True)
        self.sheet = self.workbook[sheet_name] if sheet_name else self.workbook.active

    def get_headers(self):
        """获取表头（第一行）"""
        headers = []
        for cell in self.sheet[1]:
            if cell.value is not None:
                headers.append(str(cell.value).strip())
        return headers

    def get_all_rows(self):
        """获取所有数据行（不含表头），返回字典列表"""
        headers = self.get_headers()
        data = []
        for row in self.sheet.iter_rows(min_row=2, values_only=True):
            if all(c is None for c in row):
                continue  # 跳过空行
            row_data = {}
            for i, value in enumerate(row):
                if i < len(headers):
                    row_data[headers[i]] = value
            data.append(row_data)
        return data

    def get_row_count(self):
        """获取数据行数（不含表头）"""
        return self.sheet.max_row - 1

    def get_cell(self, row, col):
        """获取指定单元格（row/col 从 1 开始）"""
        return self.sheet.cell(row=row, column=col).value

    def close(self):
        self.workbook.close()

    def __enter__(self):
        return self

    def __exit__(self, *args):
        self.close()


# 便捷函数
def load_excel(file_path, sheet_name=None):
    """读取 Excel 返回字典列表"""
    with ExcelReader(file_path, sheet_name) as reader:
        return reader.get_all_rows()
```

### 4.4 在用例中使用

```python
import pytest
from utils.excel_reader import load_excel

LOGIN_DATA = load_excel('data/login_data.xlsx')
```

## 五、YAML 数据驱动（推荐）

YAML 支持嵌套结构，比 CSV/Excel 更适合复杂场景。

### 5.1 安装

```bash
pip install pyyaml
```

### 5.2 YAML 文件示例

```yaml
# data/login_data.yaml
- username: admin
  password: Admin@123
  expected: success
  description: 正常登录

- username: admin
  password: wrongpass
  expected: fail
  description: 密码错误

- username: guest
  password: Guest@123
  expected: success
  description: 访客登录

- username: ''
  password: ''
  expected: fail
  description: 空输入
```

### 5.3 读取 YAML

```python
import yaml
import os

def load_yaml(file_path):
    with open(file_path, 'r', encoding='utf-8') as f:
        return yaml.safe_load(f)  # 返回 list/dict

# 使用
data = load_yaml('data/login_data.yaml')
```

### 5.4 综合配置文件示例

YAML 适合存"环境配置 + 测试数据"：

```yaml
# config/config.yaml
env: test

urls:
  test: https://test.example.com
  staging: https://staging.example.com
  prod: https://www.example.com

browser:
  name: chrome
  headless: false

accounts:
  admin:
    username: admin
    password: Admin@123
  guest:
    username: guest
    password: Guest@123
```

```python
# config_loader.py
import yaml
import os

class Config:
    _data = None

    @classmethod
    def load(cls):
        if cls._data is None:
            path = os.path.join(os.path.dirname(__file__), 'config.yaml')
            with open(path, 'r', encoding='utf-8') as f:
                cls._data = yaml.safe_load(f)
        return cls._data

    @classmethod
    def get_url(cls, env=None):
        data = cls.load()
        env = env or data.get('env', 'test')
        return data['urls'][env]
```

## 七、数据驱动最佳实践

1. **数据与代码分离**：测试数据放 `data/` 目录，不入代码库
2. **一份用例 + 多份数据**：避免为每组数据写一个用例
3. **数据带 description 字段**：用于生成可读的用例 ID
4. **环境配置 YAML，测试数据 Excel**：YAML 适合结构化配置，Excel 适合非技术人员维护
5. **数据敏感信息脱敏**：密码用环境变量或加密存储，不入仓库
6. **数据驱动 ≠ 接口测试**：UI 自动化数据量不宜过大（10~30 组为宜），更多用例应放接口层
