## 一、Selenium 异常体系

```
WebDriverException
├── NoSuchElementException          元素找不到（定位错误 / 未加载）
├── TimeoutException               显式等待超时
├── ElementNotVisibleException     元素不可见（display:none）【Selenium 3】
├── ElementNotInteractableException 元素不可交互（被遮挡 / 不可见）【Selenium 4】
├── StaleElementReferenceException 元素引用失效（页面刷新了 / DOM 重建了）
├── ElementClickInterceptedException 点击被其他元素拦截
├── InvalidElementStateException    元素状态无效（如 disabled）
│   ├── ElementNotSelectableException
│   └── ElementNotInteractableException
├── NoAlertPresentException        alert 弹窗不存在
├── NoSuchFrameException           iframe 找不到
├── NoSuchWindowException          窗口找不到
├── InvalidSelectorException       CSS/XPath 选择器语法错误
├── SessionNotCreatedException     浏览器 session 创建失败
├── WebDriverException             其他通用错误
│   ├── MoveTargetOutOfBoundsException
│   └── ImeNotAvailableException
└── InvalidSessionIdException      session 已失效（浏览器崩溃 / 被手动关闭）
```

## 二、十大常见异常速查

| 异常 | 原因 | 解决方案 |
| --- | --- | --- |
| `NoSuchElementException` | 元素找不到 | 检查定位器、是否在 iframe、是否需要等待 |
| `TimeoutException` | 显式等待超时 | 增加超时、检查条件、检查元素是否真的会出现 |
| `ElementNotInteractableException` | 元素不可交互 | 滚动到可见、等待可见后再操作 |
| `StaleElementReferenceException` | 元素引用失效 | 重新定位元素 |
| `ElementClickInterceptedException` | 点击被拦截 | 用 JS 点击 / 等待遮挡元素消失 |
| `NoSuchWindowException` | 窗口找不到 | close 后切到其他窗口 |
| `NoSuchFrameException` | iframe 找不到 | 检查 iframe 定位器、是否在父 iframe 中 |
| `NoAlertPresentException` | alert 不存在 | 用 `EC.alert_is_present()` 等待 |
| `SessionNotCreatedException` | 浏览器启动失败 | 检查驱动版本、浏览器版本 |
| `InvalidSessionIdException` | session 失效 | 重启浏览器 |

## 三、基础异常捕获

### 3.1 精准捕获

```python
from selenium.common.exceptions import (
    NoSuchElementException,
    TimeoutException,
    ElementNotInteractableException,
    StaleElementReferenceException
)

try:
    element = WebDriverWait(driver, 10).until(
        EC.visibility_of_element_located((By.ID, 'kw'))
    )
    element.send_keys('hello')
except TimeoutException:
    print('元素 10 秒内未出现')
except NoSuchElementException:
    print('元素根本不存在')
except ElementNotInteractableException:
    print('元素不可交互（被遮挡或不可见）')
```

### 3.2 兜底捕获

```python
from selenium.common.exceptions import WebDriverException

try:
    # 操作代码
    pass
except WebDriverException as e:
    # 捕获所有 Selenium 异常
    print(f'Selenium 异常: {e}')
    # 截图保留现场
    driver.save_screenshot('error.png')
except Exception as e:
    # 捕获所有其他异常（断言失败等）
    print(f'其他异常: {e}')
finally:
    # 无论成功失败都执行
    pass
```

> [!warning] 不要裸 except
> ```python
> except:  # 错误：会吞掉所有异常包括 KeyboardInterrupt
>     pass
> ```
> 至少用 `except Exception as e`。

## 四、StaleElementReference 处理

页面 AJAX 刷新后，之前定位的元素引用会失效。解决：**重新定位**。

```python
from selenium.common.exceptions import StaleElementReferenceException
import time

def safe_click(driver, locator, max_retry=3):
    """安全点击：处理 StaleElementReference"""
    for attempt in range(max_retry):
        try:
            element = driver.find_element(*locator)
            element.click()
            return True
        except StaleElementReferenceException:
            print(f'元素失效，重试 {attempt+1}/{max_retry}')
            time.sleep(0.5)
        except ElementNotInteractableException:
            # 滚动到可见后重试
            driver.execute_script(
                'arguments[0].scrollIntoView({block: "center"})',
                driver.find_element(*locator)
            )
            time.sleep(0.3)
    raise Exception(f'点击失败，重试 {max_retry} 次后仍失败: {locator}')
```

## 五、通用重试装饰器

```python
"""
重试装饰器
位置：utils/retry.py
"""
import time
import functools
from selenium.common.exceptions import (
    TimeoutException,
    StaleElementReferenceException,
    ElementNotInteractableException,
    ElementClickInterceptedException,
    WebDriverException
)


def retry(max_attempts=3, delay=1, exceptions=None, on_failure=None):
    """
    通用重试装饰器
    :param max_attempts: 最大重试次数
    :param delay: 重试间隔（秒）
    :param exceptions: 触发重试的异常元组，默认 Selenium 常见异常
    :param on_failure: 全部失败后的回调
    """
    if exceptions is None:
        exceptions = (
            TimeoutException,
            StaleElementReferenceException,
            ElementNotInteractableException,
            ElementClickInterceptedException,
            WebDriverException,
        )

    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            last_exception = None
            for attempt in range(1, max_attempts + 1):
                try:
                    return func(*args, **kwargs)
                except exceptions as e:
                    last_exception = e
                    print(f'{func.__name__} 第 {attempt}/{max_attempts} 次失败: {e}')
                    if attempt < max_attempts:
                        time.sleep(delay)
            # 全部失败
            if on_failure:
                on_failure(last_exception)
            raise last_exception
        return wrapper
    return decorator


# 使用示例
@retry(max_attempts=3, delay=1)
def click_element(driver, locator):
    driver.find_element(*locator).click()


# 在 PO 方法上用
class LoginPage(BasePage):
    @retry(max_attempts=2, delay=0.5)
    def login(self, username, password):
        self.type(self.username_input, username)
        self.type(self.password_input, password)
        self.click(self.login_btn)
```

## 六、统一异常处理（PO 层）

在 BasePage 中统一处理常见异常，让业务方法保持简洁：

```python
class BasePage:
    def __init__(self, driver):
        self.driver = driver
        self.wait = WaitHelper(driver)

    def click(self, locator, retry=2):
        """统一处理点击的常见异常"""
        for attempt in range(retry + 1):
            try:
                el = self.wait.element_clickable(locator)
                # 滚动到可见，避免被遮挡
                self.driver.execute_script(
                    'arguments[0].scrollIntoView({block: "center"})', el
                )
                el.click()
                return self
            except ElementClickInterceptedException:
                # 点击被拦截，用 JS 点击兜底
                try:
                    self.driver.execute_script('arguments[0].click()', el)
                    return self
                except Exception:
                    pass
            except StaleElementReferenceException:
                if attempt < retry:
                    time.sleep(0.5)
                    continue
                raise
        raise Exception(f'点击失败: {locator}')

    def type(self, locator, text, retry=2):
        """统一处理输入的常见异常"""
        for attempt in range(retry + 1):
            try:
                el = self.wait.element_visible(locator)
                el.clear()
                el.send_keys(text)
                return self
            except StaleElementReferenceException:
                if attempt < retry:
                    time.sleep(0.5)
                    continue
                raise
            except ElementNotInteractableException:
                if attempt < retry:
                    self.driver.execute_script(
                        'arguments[0].scrollIntoView()', self.driver.find_element(*locator)
                    )
                    time.sleep(0.3)
                    continue
                raise
```

## 七、用例层异常处理

### 7.1 失败自动截图 + 日志

```python
# conftest.py
import pytest
from utils.logger import logger
from utils.screenshot import ScreenshotHelper
import os
from datetime import datetime


@pytest.hookimpl(hookwrapper=True)
def pytest_runtest_makereport(item, call):
    outcome = yield
    report = outcome.get_result()

    if report.when == 'call':
        if report.failed:
            driver = item.funcargs.get('driver')
            if driver:
                try:
                    sh = ScreenshotHelper(driver)
                    path = sh.take(f'FAIL_{item.name}')
                    logger.error(f'用例 {item.name} 失败，截图: {path}')
                    logger.error(f'失败原因: {report.longrepr}')
                except Exception as e:
                    logger.error(f'截图失败: {e}')
        elif report.passed:
            logger.info(f'用例 {item.name} 通过')
```

### 7.2 用例内 try-except

```python
def test_login(driver):
    login_page = LoginPage(driver)
    try:
        login_page.load().login('admin', 'Admin@123')
        assert HomePage(driver).is_loaded()
    except TimeoutException as e:
        pytest.fail(f'登录超时，可能页面未加载: {e}')
    except Exception as e:
        pytest.fail(f'登录异常: {e}')
```

> [!tip] 推荐
> 用例层尽量少写 try-except，让异常自然抛出由 pytest 报告。**异常处理集中在 PO/工具层**，用例只做断言。

## 八、SessionNotCreated 排查

最常见的环境问题：

```python
try:
    driver = webdriver.Chrome()
except SessionNotCreatedException as e:
    # 通常是驱动版本不匹配
    print(f'浏览器启动失败: {e}')
    print('排查步骤:')
    print('1. 检查 Chrome 版本: chrome://version/')
    print('2. 检查 chromedriver 版本是否匹配')
    print('3. 让 Selenium Manager 自动下载，或手动指定驱动路径')
```

## 九、异常处理原则

1. **精准捕获 > 宽泛捕获**：优先用具体异常类
2. **异常处理集中在工具层**：用例层保持简洁
3. **失败必留现场**：截图 + 日志 + 异常堆栈
4. **可恢复才重试**：网络抖动、元素失效可重试；定位错误重试无意义
5. **不要吞异常**：捕获后至少记录日志，不要 `except: pass`
6. **区分业务异常 vs 系统异常**：业务异常（登录失败）是预期内的，系统异常（驱动崩溃）需要报警
