## 二、简单滑块（左到右）

### 2.1 基础拖拽（会被识别）

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver import ActionChains

wd = webdriver.Chrome()
wd.get('https://www.example.com/slider')

slider = wd.find_element(By.CSS_SELECTOR, '.slider-btn')
track = wd.find_element(By.CSS_SELECTOR, '.slider-track')

# 获取轨道宽度
track_width = track.size['width']

# 拖拽
ActionChains(wd).click_and_hold(slider) \
    .move_by_offset(track_width, 0) \
    .release() \
    .perform()
```

> [!danger] 一拖到底会被识别
> 上面这种"按住→直接移到终点→释放"的方式轨迹是直线、速度恒定，**会被反爬识别为机器人**。需要模拟人手的加速 → 减速 → 微调轨迹。

### 2.2 模拟人手轨迹（关键）

人手拖滑块的特征：
1. **先加速后减速**（符合贝塞尔曲线 / 缓动函数）
2. **会有微小过冲**（拖过头再回拉）
3. **中间有停顿**（思考）
4. **释放前有轻微抖动**

```python
import random
import time

def get_track(distance):
    """
    生成模拟人手的滑动轨迹
    :param distance: 需要滑动的总距离
    :return: 轨迹列表，每个元素是一次移动的 x 偏移
    """
    track = []
    current = 0       # 已移动距离
    v = 0             # 当前速度
    mid = distance * 4 / 5   # 减速阈值（前 4/5 加速，后 1/5 减速）
    t = 0.2           # 时间间隔
    a = 2             # 加速度

    while current < distance:
        if current < mid:
            # 加速阶段
            a = 2
        else:
            # 减速阶段
            a = -3

        v = v + a * t
        move = v * t + 0.5 * a * t * t
        move = max(1, move)  # 至少移动 1 像素

        current += move
        if current > distance:
            # 过冲，最后一步精确修正
            move = move - (current - distance)
            track.append(round(move, 2))
            break
        track.append(round(move, 2))

    return track


def drag_slider_human_like(driver, slider, distance, y_jitter=2):
    """模拟人手拖动滑块"""
    actions = ActionChains(driver)
    actions.click_and_hold(slider)

    track = get_track(distance)

    for x in track:
        # 加随机 Y 抖动
        y = random.uniform(-y_jitter, y_jitter)
        actions.move_by_offset(x, y)
        time.sleep(random.uniform(0.01, 0.03))

    # 短暂停顿（人手会犹豫）
    time.sleep(random.uniform(0.1, 0.3))

    # 过冲后回拉
    overshoot = random.randint(3, 10)
    actions.move_by_offset(overshoot, 0)
    time.sleep(0.1)
    actions.move_by_offset(-overshoot, 0)

    # 释放前再停顿
    time.sleep(random.uniform(0.05, 0.15))
    actions.release().perform()
```

### 2.3 完整示例：拖到轨道末端

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

wd = webdriver.Chrome()
wd.get('https://www.example.com/slider')

# 等待滑块可点击
slider = WebDriverWait(wd, 10).until(
    EC.element_to_be_clickable((By.CSS_SELECTOR, '.slider-btn'))
)

# 轨道宽度 - 滑块宽度 = 实际需要滑动的距离
track = wd.find_element(By.CSS_SELECTOR, '.slider-track')
slider_width = slider.size['width']
track_width = track.size['width']
distance = track_width - slider_width - 5  # 留 5px 余量

# 模拟人手拖动
drag_slider_human_like(wd, slider, distance)

# 等待验证结果
time.sleep(2)
success = wd.find_element(By.CSS_SELECTOR, '.slider-tip').text
print('验证结果:', success)
```

## 三、拼图滑块（带缺口）

### 3.1 思路

拼图滑块的关键是 **找到缺口位置**，然后拖过去。识别缺口的方法：

1. **对比完整图和缺口图**（站点会返回两张图）
2. **OpenCV 边缘检测**（站点只返回一张带缺口图）

### 3.2 用 OpenCV 识别缺口位置

```bash
pip install opencv-python numpy pillow
```

```python
import cv2
import numpy as np
from PIL import Image
import requests
import io

def find_gap_position(image_url, save_path='gap.png'):
    """
    识别拼图缺口位置
    :param image_url: 缺口图片 URL
    :return: 缺口左边缘的 x 坐标
    """
    # 下载图片
    resp = requests.get(image_url)
    img = Image.open(io.BytesIO(resp.content))
    img.save(save_path)

    # 读为灰度图
    gray = cv2.imread(save_path, cv2.IMREAD_GRAYSCALE)

    # 高斯模糊去噪
    blurred = cv2.GaussianBlur(gray, (5, 5), 0)

    # Canny 边缘检测
    edges = cv2.Canny(blurred, 100, 200)

    # 找轮廓
    contours, _ = cv2.findContours(edges, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

    # 过滤出缺口轮廓（缺口一般是矩形，面积较大）
    for contour in sorted(contours, key=cv2.contourArea, reverse=True)[:5]:
        x, y, w, h = cv2.boundingRect(contour)
        # 缺口宽高比通常在 0.5~2 之间，且面积适中
        if 40 < w < 100 and 40 < h < 100:
            return x

    return None

# 使用
gap_x = find_gap_position('https://www.example.com/captcha.png')
print(f'缺口位置: {gap_x}')
```

### 5.2 滑动速度控制

```python
# 总时长建议在 1.5~3 秒之间
# 太快（<1s）必被识别为机器
# 太慢（>5s）用户体验差，也可能触发其他检测

# 每步移动 1~5 像素，间隔 10~30ms
```

### 5.3 失败重试

```python
def try_solve_slider(driver, max_retry=3):
    for attempt in range(max_retry):
        try:
            # 执行滑动
            drag_slider_human_like(...)
            time.sleep(2)
            # 判断是否成功
            if '成功' in driver.find_element(By.CSS_SELECTOR, '.tip').text:
                return True
            # 失败则刷新验证码重试
            driver.find_element(By.CSS_SELECTOR, '.refresh').click()
            time.sleep(1)
        except Exception as e:
            print(f'第 {attempt+1} 次失败: {e}')
    return False
```

## 六、其他验证码方案

| 类型 | 方案 |
| --- | --- |
| 图形验证码（4 位字母数字） | 接入打码平台（超级鹰、图鉴）或本地 OCR（ddddocr） |
| 短信验证码 | 用短信转发服务 / 测试环境固定验证码 |
| 行为验证码 | 模拟鼠标轨迹 + 减少自动化特征 |
| reCAPTCHA / hCaptcha | 接入第三方打码服务，不推荐自己破解 |
