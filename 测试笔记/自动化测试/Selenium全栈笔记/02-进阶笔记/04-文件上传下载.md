# 文件上传与下载

> [!info] 本节目标
> 掌握文件上传（input 标签 / 非 input 标签 / 系统弹窗）、文件下载（设置默认下载路径 + 等待）的完整方案。

相关笔记：[[06-JS执行]]、[[03-多浏览器兼容]]

## 一、文件上传

### 1.1 场景一：input 标签（最常见，最简单）

HTML 中 `<input type="file">` 标签可直接用 `send_keys()` 上传文件路径：

```python
from selenium import webdriver
from selenium.webdriver.common.by import By

wd = webdriver.Chrome()
wd.get('https://www.example.com/upload')

# 定位 input[type=file]
file_input = wd.find_element(By.CSS_SELECTOR, 'input[type="file"]')

# 直接 send_keys 文件绝对路径
file_input.send_keys(r'D:\test\hello.txt')

# 点击上传按钮
wd.find_element(By.ID, 'upload-btn').click()
```

> [!tip] 推荐做法
> 90% 的上传场景都是 input 标签，**优先用 `send_keys()`**，最稳定、最跨浏览器。

### 1.2 场景二：非 input 标签（按钮点击触发系统弹窗）

如果上传按钮不是 input 标签，点击会触发 **操作系统级文件选择弹窗**，Selenium 无法直接操作这种弹窗。解决方案有三种：

#### 方案 A：用 pyautogui 模拟键盘输入

```bash
pip install pyautogui
```

```python
import pyautogui
import time

# 1. 点击上传按钮触发系统弹窗
wd.find_element(By.ID, 'upload-btn').click()

# 2. 等待弹窗出现
time.sleep(1)

# 3. 用 pyautogui 输入文件路径并回车
pyautogui.write(r'D:\test\hello.txt', interval=0.05)
pyautogui.press('enter')
```

> [!warning] pyautogui 的局限
> - 必须是 **有头模式**（headless 不可用）
> - 输入路径不能有中文（pyautogui 对中文支持差）
> - 受系统焦点影响，弹窗必须处于焦点状态

#### 方案 B：用 pywinauto 操作 Windows 弹窗（仅 Windows）

```bash
pip install pywinauto
```

```python
import pywinauto
import time

# 点击上传按钮触发弹窗
wd.find_element(By.ID, 'upload-btn').click()
time.sleep(1)

# 连接到文件选择弹窗
app = pywinauto.Application().connect(title='打开')
dialog = app.window(title='打开')

# 输入文件路径
dialog.edit.set_edit_text(r'D:\test\hello.txt')

# 点击"打开"按钮
dialog['打开(O)'].click()
```

#### 方案 C：用 AutoIt 脚本（仅 Windows）

1. 安装 AutoIt，编写脚本 `upload.au3`：
   ```autoit
   WinWait("打开", "")
   WinActivate("打开", "")
   ControlSetText("打开", "", "Edit1", $CmdLine[1])
   ControlClick("打开", "", "Button1")
   ```
2. 编译成 `upload.exe`
3. Python 调用：
   ```python
   import subprocess
   wd.find_element(By.ID, 'upload-btn').click()
   time.sleep(1)
   subprocess.Popen([r'D:\tools\upload.exe', r'D:\test\hello.txt']).wait()
   ```

### 1.3 场景三：多个文件上传

```python
# 用 \n 分隔多个文件路径
files = r'D:\test\a.txt' + '\n' + r'D:\test\b.txt'
file_input.send_keys(files)
```

> [!note] 多文件上传依赖网站实现
> 部分网站的多文件上传是分多次 input，需要分别 `send_keys`。

## 二、文件下载

### 2.1 Chrome 设置默认下载路径

```python
from selenium import webdriver
import os

download_dir = os.path.abspath('./downloads')
os.makedirs(download_dir, exist_ok=True)

options = webdriver.ChromeOptions()

# Chrome 下载配置
prefs = {
    'download.default_directory': download_dir,    # 默认下载目录
    'download.prompt_for_download': False,         # 不弹下载询问框
    'download.directory_upgrade': True,
    'safebrowsing.enabled': True,                  # 关闭安全检查弹窗
    'plugins.always_open_pdf_externally': True     # PDF 直接下载不预览
}
options.add_experimental_option('prefs', prefs)

wd = webdriver.Chrome(options=options)
wd.get('https://www.example.com/files')
wd.find_element(By.LINK_TEXT, '下载文件').click()
```

### 2.2 Edge 设置默认下载路径

```python
options = webdriver.EdgeOptions()
prefs = {
    'download.default_directory': download_dir,
    'download.prompt_for_download': False,
}
options.add_experimental_option('prefs', prefs)
wd = webdriver.Edge(options=options)
```

### 2.3 Firefox 设置默认下载路径

```python
options = webdriver.FirefoxOptions()

# 设置浏览器类型为 2（自定义下载目录）
options.set_preference('browser.download.folderList', 2)
options.set_preference('browser.download.dir', download_dir)
options.set_preference('browser.download.manager.showWhenStarting', False)
# 不弹询问框的 MIME 类型
options.set_preference('browser.helperApps.neverAsk.saveToDisk',
                       'application/octet-stream,'
                       'application/vnd.ms-excel,'
                       'application/pdf,'
                       'application/zip')

wd = webdriver.Firefox(options=options)
```

### 2.4 等待下载完成

下载是异步的，需要轮询判断文件是否下载完成：

```python
import os
import time

def wait_download_complete(download_dir, file_prefix='', timeout=60):
    """
    等待下载完成
    :param download_dir: 下载目录
    :param file_prefix: 文件名前缀（可选）
    :param timeout: 超时秒数
    :return: 下载完成的文件路径，超时返回 None
    """
    deadline = time.time() + timeout
    while time.time() < deadline:
        # 找 .crdownload 临时文件（Chrome 下载中）
        files = [f for f in os.listdir(download_dir) if not f.endswith('.crdownload')]
        # 排除 .part 临时文件（Firefox）
        files = [f for f in files if not f.endswith('.part')]

        if file_prefix:
            files = [f for f in files if f.startswith(file_prefix)]

        # 等到至少有一个非临时文件且没有 .crdownload
        has_temp = any(f.endswith(('.crdownload', '.part')) for f in os.listdir(download_dir))
        if files and not has_temp:
            return os.path.join(download_dir, files[0])

        time.sleep(0.5)
    return None

# 使用
wd.find_element(By.LINK_TEXT, '下载').click()
file_path = wait_download_complete(download_dir, file_prefix='report')
if file_path:
    print(f'下载完成: {file_path}')
else:
    print('下载超时')
```

## 三、封装文件操作工具类

```python
"""
文件上传下载工具类
位置：utils/file_helper.py
"""
import os
import time
import pyautogui
from selenium.webdriver.common.by import By


class FileHelper:

    @staticmethod
    def upload_via_input(driver, input_locator, file_path):
        """通过 input[type=file] 标签上传"""
        file_path = os.path.abspath(file_path)
        driver.find_element(*input_locator).send_keys(file_path)
        return file_path

    @staticmethod
    def upload_via_pyautogui(driver, button_locator, file_path, wait=1.5):
        """用 pyautogui 处理非 input 上传弹窗（路径不能有中文）"""
        file_path = os.path.abspath(file_path)
        driver.find_element(*button_locator).click()
        time.sleep(wait)
        pyautogui.write(file_path, interval=0.05)
        time.sleep(0.3)
        pyautogui.press('enter')
        time.sleep(0.5)

    @staticmethod
    def wait_download_complete(download_dir, file_prefix='', timeout=60):
        """等待下载完成，返回文件路径"""
        deadline = time.time() + timeout
        while time.time() < deadline:
            files = [f for f in os.listdir(download_dir)
                     if not f.endswith(('.crdownload', '.part'))]
            if file_prefix:
                files = [f for f in files if f.startswith(file_prefix)]
            has_temp = any(f.endswith(('.crdownload', '.part'))
                           for f in os.listdir(download_dir))
            if files and not has_temp:
                return os.path.join(download_dir, files[0])
            time.sleep(0.5)
        return None

    @staticmethod
    def get_latest_file(directory):
        """获取目录下最新修改的文件"""
        files = [os.path.join(directory, f) for f in os.listdir(directory)]
        if not files:
            return None
        return max(files, key=os.path.getmtime)
```

## 四、常见问题

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| `file_input.send_keys()` 报 `invalid argument: File not found` | 文件路径错误或文件不存在 | 用 `os.path.abspath()` 转绝对路径，确认文件存在 |
| 上传按钮点击后无反应 | 按钮在 iframe 中 | 先 `switch_to.frame()` |
| 中文路径上传失败 | pyautogui 不支持中文 | 改用 pywinauto 或先把文件移到英文路径 |
| 下载文件找不到了 | Chrome 配置没生效 | 确认 `prefs` 在 `add_experimental_option` 中正确传入 |
| 下载一直等不到完成 | `.crdownload` 临时文件没清干净 | 检查目录，手动清理 |
