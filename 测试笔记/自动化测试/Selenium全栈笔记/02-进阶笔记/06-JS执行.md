# JavaScript 执行

> [!info] 本节目标
> 掌握 `execute_script` 与 `execute_async_script` 的使用场景，用 JS 解决 Selenium 原生 API 搞不定的"疑难杂症"：滚动、隐藏元素、富文本、属性修改、富交互页面。

相关笔记：[[04-基础操作]]、[[07-滑块验证码处理]]、[[11-页面性能获取]]

## 一、为什么需要执行 JS

Selenium 原生 API 有局限，以下场景必
须（或更适合）用 JS：

| 场景 | 原生 API 的局限 | JS 方案 |
| --- | --- | --- |
| 元素在视口外，需要滚动到可见 | `click()` 报 `ElementNotInteractable` | `scrollIntoView()` |
| 元素被 `display:none` 隐藏，但需要取值 | `text` 返回空 | `innerText` / `getAttribute` |
| 富文本编辑器（div + contenteditable） | `send_keys` 不生效 | 直接设 `innerHTML` |
| 移除 readonly / disabled 属性 | 无法修改属性 | `removeAttribute()` |
| 修改 input 值触发前端事件 | `send_keys` 触发不全 | 设 value 后触发 `input` 事件 |
| 获取页面性能数据 | 无 API | `performance.timing` |
| 跨域 Cookie / localStorage 操作 | 受限 | `localStorage.getItem()` |

## 二、`execute_script` 基础用法

### 2.1 同步执行 JS

```python
# 语法
result = driver.execute_script(script, *args)

# 返回值规则：
# - JS 返回 null/undefined → Python 收到 None
# - JS 返回基本类型 → 对应 Python 类型
# - JS 返回 HTML 元素 → WebElement
# - JS 返回数组/对象 → Python list/dict
```

### 2.2 第一个例子：弹 alert

```python
from selenium import webdriver

wd = webdriver.Chrome()
wd.get('https://www.baidu.com')

# 执行 JS 弹窗
wd.execute_script('alert("hello from selenium")')
```

### 2.3 传参给 JS

JS 中用 `arguments[0]`、`arguments[1]` 接收 Python 传入的参数：

```python
# 传入字符串
wd.execute_script('console.log(arguments[0])', 'hello')

# 传入 WebElement
element = wd.find_element(By.ID, 'kw')
wd.execute_script('arguments[0].style.border = "3px solid red"', element)

# 传入多个参数
wd.execute_script(
    'arguments[0].value = arguments[1]',
    input_element, 'new value'
)
```

### 2.4 返回值给 Python

```python
# 返回字符串
title = wd.execute_script('return document.title')
print(title)

# 返回数字
height = wd.execute_script('return document.body.scrollHeight')
print(height)

# 返回元素
element = wd.execute_script('return document.getElementById("kw")')
element.send_keys('hello')

# 返回数组
texts = wd.execute_script(
    'return Array.from(document.querySelectorAll("h3")).map(e => e.innerText)'
)
print(texts)  # ['标题1', '标题2', ...]

# 返回对象
info = wd.execute_script(
    'return {title: document.title, url: location.href}'
)
print(info)  # {'title': '...', 'url': '...'}
```

## 三、经典场景

### 3.1 滚动到元素可见

```python
element = wd.find_element(By.ID, 'submit')

# 滚动到元素
wd.execute_script('arguments[0].scrollIntoView({block: "center"})', element)
element.click()
```

### 3.2 滚动到页面底部 / 顶部

```python
# 滚到底部
wd.execute_script('window.scrollTo(0, document.body.scrollHeight)')

# 滚到顶部
wd.execute_script('window.scrollTo(0, 0)')

# 滚动指定像素
wd.execute_script('window.scrollBy(0, 500)')

# 平滑滚动
wd.execute_script('window.scrollTo({top: document.body.scrollHeight, behavior: "smooth"})')
```

### 3.3 操作隐藏元素

```python
# 获取 display:none 元素的文本（原生 .text 返回空）
text = wd.execute_script(
    'return arguments[0].innerText',
    wd.find_element(By.CSS_SELECTOR, '.hidden-text')
)
print(text)

# 让隐藏元素可见
wd.execute_script('arguments[0].style.display = "block"', hidden_element)

# 移除 readonly 属性
wd.execute_script('arguments[0].removeAttribute("readonly")', readonly_input)

# 移除 disabled 属性
wd.execute_script('arguments[0].removeAttribute("disabled")', disabled_btn)
```

### 3.4 富文本编辑器（contenteditable div）

```python
# 很多富文本编辑器是 div + contenteditable="true"，send_keys 不生效
editor = wd.find_element(By.CSS_SELECTOR, '.ql-editor')

# 方法 1：直接设 innerHTML
wd.execute_script('arguments[0].innerHTML = "<p>Hello World</p>"', editor)

# 方法 2：设 innerText（更安全，避免 HTML 注入）
wd.execute_script('arguments[0].innerText = "Hello World"', editor)
```

### 3.5 修改 input 值并触发事件

部分前端框架（Vue / React）监听的是 `input` 事件，单纯改 `value` 不会触发：

```python
def set_input_value(driver, element, value):
    """设置 input 值并触发 input/change 事件"""
    script = """
        arguments[0].value = arguments[1];
        arguments[0].dispatchEvent(new Event('input', {bubbles: true}));
        arguments[0].dispatchEvent(new Event('change', {bubbles: true}));
    """
    driver.execute_script(script, element, value)

# 使用
input_el = wd.find_element(By.ID, 'username')
set_input_value(wd, input_el, 'dean')
```

### 3.6 高亮元素（调试用）

```python
def highlight(driver, element, color='red', duration=2):
    """高亮元素，调试定位时很有用"""
    driver.execute_script(
        f'arguments[0].style.border = "3px solid {color}"',
        element
    )
    import time
    time.sleep(duration)
    driver.execute_script('arguments[0].style.border = ""', element)
```

### 3.7 修改 window 属性（防检测）

```python
# 修改 webdriver 标志（见 [[03-多浏览器兼容]]）
wd.execute_cdp_cmd('Page.addScriptToEvaluateOnNewDocument', {
    'source': 'Object.defineProperty(navigator, "webdriver", {get: () => undefined})'
})
```

## 四、`execute_async_script` 异步执行

### 4.1 同步 vs 异步

```python
# 同步：JS 执行完立即返回，无法等异步操作
result = driver.execute_script(script)

# 异步：JS 中需要调用 arguments[arguments.length-1] 回调
#       Selenium 会等待回调被调用（受 set_script_timeout 控制）
result = driver.execute_async_script(script)
```

### 4.2 设置异步超时

```python
# 默认异步脚本超时是 0（立即超时），必须显式设置
wd.set_script_timeout(30)  # 30 秒
```

### 4.3 异步示例：等待 AJAX 完成

```python
wd.set_script_timeout(30)

# 等待 fetch 请求完成
script = """
    var callback = arguments[arguments.length - 1];
    fetch('/api/data')
        .then(r => r.json())
        .then(data => callback(data))
        .catch(err => callback({error: err.message}));
"""
result = wd.execute_async_script(script)
print(result)
```

### 4.4 异步示例：等待某个条件

```python
# 轮询等待某个元素出现文本
script = """
    var callback = arguments[arguments.length - 1];
    var el = arguments[0];
    var expected = arguments[1];

    function check() {
        if (el.innerText.includes(expected)) {
            callback(true);
        } else {
            setTimeout(check, 200);
        }
    }
    check();
"""
element = wd.find_element(By.ID, 'status')
ok = wd.execute_async_script(script, element, '完成')
```

## 五、JS 工具类封装

```python
"""
JS 工具类
位置：utils/js_helper.py
"""
from selenium.webdriver.common.by import By


class JsHelper:

    def __init__(self, driver):
        self.driver = driver

    def execute(self, script, *args):
        """同步执行 JS"""
        return self.driver.execute_script(script, *args)

    def execute_async(self, script, *args, timeout=30):
        """异步执行 JS"""
        self.driver.set_script_timeout(timeout)
        return self.driver.execute_async_script(script, *args)

    def scroll_to_element(self, element):
        """滚动到元素可见"""
        self.execute('arguments[0].scrollIntoView({block: "center"})', element)

    def scroll_to_bottom(self):
        self.execute('window.scrollTo(0, document.body.scrollHeight)')

    def scroll_to_top(self):
        self.execute('window.scrollTo(0, 0)')

    def scroll_by(self, x, y):
        self.execute(f'window.scrollBy({x}, {y})')

    def get_inner_text(self, element):
        """获取元素 innerText（含隐藏文本）"""
        return self.execute('return arguments[0].innerText', element)

    def set_value(self, element, value, trigger_event=True):
        """设置 input 值（可触发事件）"""
        if trigger_event:
            script = """
                arguments[0].value = arguments[1];
                arguments[0].dispatchEvent(new Event('input', {bubbles: true}));
                arguments[0].dispatchEvent(new Event('change', {bubbles: true}));
            """
            self.execute(script, element, value)
        else:
            self.execute('arguments[0].value = arguments[1]', element, value)

    def remove_attribute(self, element, attr):
        """移除元素属性"""
        self.execute(f'arguments[0].removeAttribute("{attr}")', element)

    def set_display(self, element, display='block'):
        """设置元素 display"""
        self.execute(f'arguments[0].style.display = "{display}"', element)

    def set_inner_html(self, element, html):
        """设置元素 innerHTML（富文本编辑器）"""
        self.execute('arguments[0].innerHTML = arguments[1]', element, html)

    def highlight(self, element, color='red', duration=1):
        """高亮元素（调试用）"""
        import time
        self.execute(f'arguments[0].style.border = "3px solid {color}"', element)
        time.sleep(duration)
        self.execute('arguments[0].style.border = ""', element)
```

## 六、注意事项

1. **JS 字符串转义**：脚本里用双引号，外层 Python 用单引号，或用三引号
2. **不要滥用 JS 替代原生 API**：能用 `click()` 就别用 JS 点击，原生更接近真实用户
3. **异步脚本必须设超时**：`set_script_timeout` 不设会立刻超时
4. **execute_cdp_cmd**：Chrome 专属，可执行 DevTools Protocol 命令（性能、网络、设备模拟）
