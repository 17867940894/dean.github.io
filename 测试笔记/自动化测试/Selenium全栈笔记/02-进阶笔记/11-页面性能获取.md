# 页面性能获取

> [!info] 本节目标
> 掌握用 Selenium 获取页面性能指标的三种方式：`performance.timing` API、Chrome DevTools Protocol（CDP）、Lighthouse 集成，能输出页面加载耗时报告。

相关笔记：[[06-JS执行]]、[[05-截图日志]]

## 一、为什么用 Selenium 做性能测试

| 工具 | 适用场景 | 局限 |
| --- | --- | --- |
| JMeter / LoadRunner | 接口级压测、高并发 | 无法模拟真实浏览器渲染 |
| Lighthouse CLI | 单页面性能审计 | 不支持登录态、多步操作 |
| **Selenium + Performance API** | **真实浏览器、登录后页面、多步操作性能** | 并发能力弱 |
| WebPageTest | 真实浏览器性能 | 不易集成到 CI |

Selenium 的优势：**能在登录态、多步业务流程后采集性能数据**，这是其他工具难以做到的。

## 二、Performance Timing API（最基础）

### 2.1 获取 timing 对象

浏览器原生提供 `window.performance.timing`，记录了页面加载各阶段的时间戳：

```python
from selenium import webdriver
import json

wd = webdriver.Chrome()
wd.get('https://www.baidu.com')

# 获取 performance.timing
timing = wd.execute_script("""
    var t = performance.timing;
    return {
        navigationStart: t.navigationStart,
        fetchStart: t.fetchStart,
        domainLookupStart: t.domainLookupStart,
        domainLookupEnd: t.domainLookupEnd,
        connectStart: t.connectStart,
        connectEnd: t.connectEnd,
        responseStart: t.responseStart,
        responseEnd: t.responseEnd,
        domLoading: t.domLoading,
        domInteractive: t.domInteractive,
        domContentLoadedEventStart: t.domContentLoadedEventStart,
        domContentLoadedEventEnd: t.domContentLoadedEventEnd,
        domComplete: t.domComplete,
        loadEventStart: t.loadEventStart,
        loadEventEnd: t.loadEventEnd
    };
""")

print(json.dumps(timing, indent=2))
```

### 2.2 计算关键指标

```python
def calc_metrics(timing):
    """从 timing 计算关键性能指标（毫秒）"""
    metrics = {
        # DNS 查询
        'DNS查询': timing['domainLookupEnd'] - timing['domainLookupStart'],
        # TCP 连接
        'TCP连接': timing['connectEnd'] - timing['connectStart'],
        # 请求响应（白屏时间 / TTFB 相关）
        '请求响应': timing['responseEnd'] - timing['responseStart'],
        # 首字节时间（TTFB）
        '首字节时间': timing['responseStart'] - timing['navigationStart'],
        # DOM 解析
        'DOM解析': timing['domInteractive'] - timing['responseEnd'],
        # 页面加载完成总耗时
        '页面加载总耗时': timing['loadEventEnd'] - timing['navigationStart'],
        # 白屏时间（首屏渲染前）
        '白屏时间': timing['responseStart'] - timing['navigationStart'],
        # DOM Ready
        'DOMReady': timing['domContentLoadedEventEnd'] - timing['navigationStart'],
    }
    return metrics

metrics = calc_metrics(timing)
for k, v in metrics.items():
    print(f'{k}: {v} ms')
```

### 2.3 等待 load 完成

`loadEventEnd` 在 load 事件触发后才不为 0，必须等待：

```python
from selenium.webdriver.support.ui import WebDriverWait

# 等待 load 完成
WebDriverWait(wd, 30).until(
    lambda d: d.execute_script('return performance.timing.loadEventEnd') > 0
)
# 然后再采集
timing = wd.execute_script('return performance.timing.toJSON()')
```

> [!warning] 注意
> `performance.timing` 已被废弃，新规范是 `PerformanceObserver` + `performance.getEntries()`。但 `timing` 仍广泛可用，作为入门方案够用。

## 三、Chrome DevTools Protocol（CDP，推荐）

### 3.1 开启性能日志

```python
from selenium import webdriver

options = webdriver.ChromeOptions()
# 开启性能日志
options.set_capability('goog:loggingPrefs', {'performance': 'ALL'})

wd = webdriver.Chrome(options=options)
wd.get('https://www.baidu.com')

# 获取性能日志
logs = wd.get_log('performance')
print(f'共 {len(logs)} 条性能日志')
```

### 3.2 解析网络请求

```python
import json

def parse_network_logs(logs):
    """解析 CDP 性能日志，提取网络请求"""
    requests = []
    for entry in logs:
        try:
            msg = json.loads(entry['message'])['message']
            method = msg['method']

            if method == 'Network.requestWillBeSent':
                req = msg['params']['request']
                requests.append({
                    'url': req['url'],
                    'method': req['method'],
                    'type': msg['params'].get('type', ''),
                    'timestamp': msg['params']['timestamp']
                })
        except (KeyError, json.JSONDecodeError):
            continue
    return requests

requests = parse_network_logs(logs)
for r in requests[:5]:
    print(f"{r['method']} {r['url'][:80]}")

print(f'总请求数: {len(requests)}')
```

### 3.3 计算请求耗时

```python
def calc_request_timing(logs):
    """配对 request 和 response，计算每个请求耗时"""
    timings = {}
    for entry in logs:
        try:
            msg = json.loads(entry['message'])['message']
            method = msg['method']
            params = msg['params']

            if method == 'Network.requestWillBeSent':
                req_id = params['requestId']
                timings[req_id] = {
                    'url': params['request']['url'],
                    'start': params['timestamp']
                }
            elif method == 'Network.responseReceived':
                req_id = params['requestId']
                if req_id in timings:
                    timings[req_id]['response_start'] = params['timestamp']
                    timings[req_id]['status'] = params['response']['status']
            elif method == 'Network.loadingFinished':
                req_id = params['requestId']
                if req_id in timings:
                    timings[req_id]['end'] = params['timestamp']
                    timings[req_id]['total'] = (
                        params['timestamp'] - timings[req_id]['start']
                    ) * 1000  # 转毫秒
        except (KeyError, json.JSONDecodeError):
            continue

    # 排序：耗时降序
    return sorted(
        [t for t in timings.values() if 'total' in t],
        key=lambda x: x['total'],
        reverse=True
    )

slow_requests = calc_request_timing(logs)
print('最慢的 5 个请求:')
for r in slow_requests[:5]:
    print(f"{r['total']:.0f}ms [{r.get('status', '?')}] {r['url'][:80]}")
```

## 四、Web Vitals 指标

现代 Web 性能看三大核心指标（Core Web Vitals）：

| 指标 | 含义 | 良好阈值 |
| --- | --- | --- |
| LCP（Largest Contentful Paint） | 最大内容渲染时间 | < 2.5s |
| FID（First Input Delay） | 首次输入延迟 | < 100ms |
| CLS（Cumulative Layout Shift） | 累积布局偏移 | < 0.1 |

### 4.1 用 JS 获取 Web Vitals

```python
# 注入 web-vitals 库（或用原生 PerformanceObserver）
wd.execute_script("""
    // 简化版 LCP 获取
    window.__lcp = 0;
    new PerformanceObserver((entryList) => {
        const entries = entryList.getEntries();
        const lastEntry = entries[entries.length - 1];
        window.__lcp = lastEntry.startTime;
    }).observe({type: 'largest-contentful-paint', buffered: true});

    // FCP
    window.__fcp = 0;
    new PerformanceObserver((entryList) => {
        window.__fcp = entryList.getEntries()[0].startTime;
    }).observe({type: 'paint', buffered: true});

    // CLS
    window.__cls = 0;
    new PerformanceObserver((entryList) => {
        for (const entry of entryList.getEntries()) {
            if (!entry.hadRecentInput) {
                window.__cls += entry.value;
            }
        }
    }).observe({type: 'layout-shift', buffered: true});
""")

# 等待页面稳定
import time
time.sleep(5)

vitals = wd.execute_script("""
    return {
        lcp: window.__lcp,
        fcp: window.__fcp,
        cls: window.__cls
    };
""")
print(f"LCP: {vitals['lcp']:.0f}ms")
print(f"FCP: {vitals['fcp']:.0f}ms")
print(f"CLS: {vitals['cls']:.3f}")
```

## 五、性能工具类封装

```python
"""
性能工具类
位置：utils/performance.py
"""
import json
import time
from selenium.webdriver.support.ui import WebDriverWait


class PerformanceHelper:

    def __init__(self, driver):
        self.driver = driver

    def wait_load_complete(self, timeout=30):
        """等待页面 load 完成"""
        WebDriverWait(self.driver, timeout).until(
            lambda d: d.execute_script('return performance.timing.loadEventEnd') > 0
        )

    def get_timing(self):
        """获取 performance.timing"""
        return self.driver.execute_script("""
            var t = performance.timing;
            return {
                navigationStart: t.navigationStart,
                fetchStart: t.fetchStart,
                domainLookupStart: t.domainLookupStart,
                domainLookupEnd: t.domainLookupEnd,
                connectStart: t.connectStart,
                connectEnd: t.connectEnd,
                responseStart: t.responseStart,
                responseEnd: t.responseEnd,
                domInteractive: t.domInteractive,
                domContentLoadedEventEnd: t.domContentLoadedEventEnd,
                domComplete: t.domComplete,
                loadEventEnd: t.loadEventEnd
            };
        """)

    def get_metrics(self):
        """计算关键性能指标"""
        t = self.get_timing()
        return {
            'DNS查询': t['domainLookupEnd'] - t['domainLookupStart'],
            'TCP连接': t['connectEnd'] - t['connectStart'],
            '首字节时间(TTFB)': t['responseStart'] - t['navigationStart'],
            'DOM解析': t['domInteractive'] - t['responseEnd'],
            'DOMReady': t['domContentLoadedEventEnd'] - t['navigationStart'],
            '页面加载总耗时': t['loadEventEnd'] - t['navigationStart'],
        }

    def get_network_requests(self):
        """获取所有网络请求"""
        logs = self.driver.get_log('performance')
        requests = []
        for entry in logs:
            try:
                msg = json.loads(entry['message'])['message']
                if msg['method'] == 'Network.requestWillBeSent':
                    req = msg['params']['request']
                    requests.append({
                        'url': req['url'],
                        'method': req['method'],
                        'type': msg['params'].get('type', '')
                    })
            except (KeyError, json.JSONDecodeError):
                continue
        return requests

    def get_slow_requests(self, top_n=10):
        """获取最慢的 N 个请求"""
        logs = self.driver.get_log('performance')
        # ... 解析逻辑同 3.3
        return self._calc_request_timing(logs)[:top_n]

    def measure_page(self, url):
        """一键测量页面性能"""
        self.driver.get(url)
        self.wait_load_complete()
        time.sleep(2)  # 等待动态内容

        metrics = self.get_metrics()
        requests = self.get_network_requests()

        return {
            'url': url,
            'metrics': metrics,
            'request_count': len(requests),
            'requests': requests[:20]
        }
```

## 六、Lighthouse 集成

Lighthouse 是 Google 的性能审计工具，可命令行调用：

```bash
# 安装
npm install -g lighthouse

# 命令行运行
lighthouse https://www.baidu.com --output html --output-path ./report.html --chrome-flags="--headless"
```

```python
# Python 调用
import subprocess

def run_lighthouse(url, output_path='reports/lighthouse.html'):
    """运行 Lighthouse 审计"""
    result = subprocess.run([
        'lighthouse', url,
        '--output', 'html',
        '--output-path', output_path,
        '--chrome-flags', '--headless --no-sandbox',
        '--quiet'
    ], capture_output=True, text=True)
    return output_path

# 使用
report = run_lighthouse('https://www.baidu.com')
print(f'报告已生成: {report}')
```

## 七、性能报告输出

```python
def generate_perf_report(results, output_path='reports/performance_report.html'):
    """生成性能报告 HTML"""
    rows = ''
    for r in results:
        m = r['metrics']
        rows += f"""
        <tr>
            <td>{r['url']}</td>
            <td>{m['首字节时间(TTFB)']} ms</td>
            <td>{m['DOMReady']} ms</td>
            <td>{m['页面加载总耗时']} ms</td>
            <td>{r['request_count']}</td>
        </tr>
        """

    html = f"""
    <html><head><meta charset="utf-8"><title>性能报告</title>
    <style>body{{font-family:sans-serif}}table{{border-collapse:collapse}}td,th{{border:1px solid #ccc;padding:8px}}</style>
    </head><body>
    <h1>页面性能报告</h1>
    <table>
    <tr><th>URL</th><th>TTFB</th><th>DOMReady</th><th>总耗时</th><th>请求数</th></tr>
    {rows}
    </table></body></html>
    """
    with open(output_path, 'w', encoding='utf-8') as f:
        f.write(html)
    return output_path
```

## 八、性能基线与告警

```python
# 设定性能基线，超过则告警
BASELINE = {
    '首字节时间(TTFB)': 800,    # ms
    'DOMReady': 3000,
    '页面加载总耗时': 5000,
}

def assert_performance(metrics, baseline=BASELINE):
    """断言性能不超基线"""
    for k, threshold in baseline.items():
        actual = metrics.get(k, 0)
        assert actual < threshold, f'{k} 超过基线: {actual}ms > {threshold}ms'
```
