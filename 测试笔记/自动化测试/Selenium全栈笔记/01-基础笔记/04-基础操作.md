## 一、元素操作

### 1.1 点击元素 `click()`

```python
from selenium import webdriver
from selenium.webdriver.common.by import By

wd = webdriver.Chrome()
wd.get('https://www.baidu.com')

# 定位"百度一下"按钮并点击
wd.find_element(By.ID, 'su').click()
```

### 1.2 输入内容 `send_keys()`

```python
# 在搜索框输入文字
wd.find_element(By.ID, 'kw').send_keys('Selenium 自动化')
```

### 1.3 清空输入框 `clear()`

```python
kw = wd.find_element(By.ID, 'kw')
kw.send_keys('hello')
kw.clear()  # 清空输入框内容
kw.send_keys('world')
```

### 1.4 获取元素文本 `text`

```python
# 获取元素的可见文本（不含子标签的 HTML，只取展示文字）
text = wd.find_element(By.CSS_SELECTOR, '.result h3').text
print(text)
```

> [!warning] 注意
> `text` 属性只能获取 **可见** 文本。如果元素 `display:none` 或在隐藏的父元素中，`text` 返回空字符串。

### 1.5 获取元素属性 `get_attribute()`

`get_attribute()` 并非全局函数

在 Python 中，`get_attribute()` 并不是一个独立的全局内置函数，它最常出现在以下 **3 个具体场景** 中，每个场景的用法和目的完全不同。

---

#### 场景一：Selenium WebDriver 中获取元素属性（最常见）

这是你大概率在找的用法，用于自动化测试中获取网页元素的 HTML 属性值。

```python
from selenium import webdriver
from selenium.webdriver.common.by import By

driver = webdriver.Chrome()
driver.get("https://example.com")

element = driver.find_element(By.ID, "submit")

# 获取标准属性
value = element.get_attribute("value")        # 获取输入框的值
href = element.get_attribute("href")          # 获取链接地址
class_name = element.get_attribute("class")   # 获取 class

# 特殊用法：获取布尔属性（如 disabled、checked）
is_disabled = element.get_attribute("disabled")  # 返回 "true"/"false" 或 None
```

**注意要点：**

- 返回值为 **字符串**，属性不存在时返回 `None`
- 对于 `checked`、`disabled` 等布尔属性，建议使用 `.is_selected()` 或 `.is_enabled()` 方法更可靠
- 同样支持获取自定义属性（如 `data-id`）

---

#### 场景二：Python 对象内部重写属性访问（元类/反射）

这是 Python 底层的魔法方法，用于控制 `对象.属性` 的访问行为，通常在编写框架或 ORM 时使用。

```python
class MyClass:
    def __getattribute__(self, name):
        # 注意：方法名是 __getattribute__，不是 get_attribute
        print(f"正在访问属性: {name}")
        return super().__getattribute__(name)

    def __getattr__(self, name):
        # 仅在属性不存在时被调用
        return f"属性 {name} 不存在，返回默认值"

obj = MyClass()
print(obj.name)  # 触发 __getattr__
```

**易混淆方法区分：**

| 方法               | 触发时机                         |
| ------------------ | -------------------------------- |
| `__getattribute__` | 访问 **任何** 属性时都会优先调用 |
| `__getattr__`      | 仅在属性 **不存在** 时调用       |

##### Python 属性访问的完整查找流程

当你写 `obj.name` 时，Python 会按以下**严格顺序**去查找这个属性：

1. **数据描述符**（最优先，如 `@property`）
2. **实例的 `__dict__`**（对象自己的属性字典）
3. **类的 `__dict__`**（类级别的属性）
4. **父类的 `__dict__`**（继承链上的属性）
5. **非数据描述符**（如普通方法）
6. **`__getattr__` 兜底方法**——如果上面全部找不到，才调用它

```text
obj.name 执行过程：
┌─────────────────────────────────────┐
│  1. 有数据描述符吗？ → 有则返回      │
│  2. 实例 __dict__ 中有 'name' 吗？   │
│  3. 类 __dict__ 中有 'name' 吗？     │
│  4. 父类中有 'name' 吗？             │
│  5. 有非数据描述符吗？               │
│  6. 以上都没有 → ⭐ 调用 __getattr__ │
└─────────────────────────────────────┘
```

```python
class Demo:
    def __init__(self):
        self.existing = "我存在"      # 实例属性

    def __getattr__(self, name):
        print(f"⚠️ 正在查找: {name}")
        return f"属性 {name} 不存在，返回默认值"

obj = Demo()

# 情况1：属性存在 → 不会触发 __getattr__
print(obj.existing)   # 输出: 我存在

# 情况2：属性不存在 → 触发 __getattr__
print(obj.unknown)    # 输出: ⚠️ 正在查找: unknown
                       #      属性 unknown 不存在，返回默认值
```

#### 场景三：第三方库中的自定义方法

部分第三方库（如某些 XML/JSON 解析库或爬虫框架）会封装自己的 `get_attribute()` 方法，用法基本一致——传入属性名，返回属性值。具体请查阅对应库的官方文档。

---

#### 快速定位：你属于哪种情况？

| 你的使用场景                 | 对应正确用法                             |
| ---------------------------- | ---------------------------------------- |
| Web 自动化测试（点击、填表） | Selenium 的 `element.get_attribute()`    |
| 编写 Python 类，控制属性访问 | 重写 `__getattribute__` 或 `__getattr__` |
| 其他未知库                   | 查阅正在使用的第三方库文档               |

---

```python
# 获取 href、value、class 等任意属性
link = wd.find_element(By.CSS_SELECTOR, 'a')
href = link.get_attribute('href')
print(href)

# 获取 input 的 value 属性
value = wd.find_element(By.ID, 'kw').get_attribute('value')
```

### 1.6 判断元素状态

```python
element = wd.find_element(By.ID, 'su')

# 是否可见
print(element.is_displayed())

# 是否启用（未 disabled）
print(element.is_enabled())

# 是否选中（checkbox / radio）
checkbox = wd.find_element(By.ID, 'agree')
print(checkbox.is_selected())
```

### 1.7 提交表单 `submit()`

```python
# 在 form 元素上调用 submit()，等同于点击表单内的提交按钮
wd.find_element(By.ID, 'form').submit()
```

## 二、浏览器操作

### 2.1 打开网址 `get()`

```python
wd.get('https://www.baidu.com')
```

### 2.2 获取和设置窗口大小

```python
# 获取窗口大小
size = wd.get_window_size()
print(size)  # {'width': 1050, 'height': 736}

# 设置窗口大小
wd.set_window_size(1280, 800)

# 窗口最大化
wd.maximize_window()

# 窗口最小化
wd.minimize_window()

# 全屏
wd.fullscreen_window()
```

### 2.3 获取标题和 URL

```python
# 获取当前页面标题
print(wd.title)

# 获取当前页面 URL
print(wd.current_url)
```

### 2.4 页面源码

```python
# 获取当前页面 HTML 源码
html = wd.page_source
print(html[:500])
```

## 三、导航操作

```python
# 后退
wd.back()
# 前进
wd.forward()
# 刷新
wd.refresh()
# 打开新网址（等价于 get）
wd.get('https://www.bing.com')
```

## 四、窗口句柄与多标签页

### 4.1 获取当前窗口句柄

```python
# 当前窗口的句柄（字符串）
current = wd.current_window_handle
print(current)
```

### 4.2 获取所有窗口句柄

```python
# 所有窗口的句柄列表
handles = wd.window_handles
print(handles)  # ['CDwindow-xxx', 'CDwindow-yyy']
```

### 4.3 切换窗口

```python
# 假设点击一个链接后打开了新窗口
wd.find_element(By.LINK_TEXT, '新闻').click()

# 获取所有句柄
handles = wd.window_handles

# 切换到最后一个（最新打开的）窗口
wd.switch_to.window(handles[-1])

print('当前窗口标题:', wd.title)

# 切回原窗口
wd.switch_to.window(handles[0])
```

> [!tip] 多窗口切换通用封装
> 见 [[06-弹窗iframe窗口切换]] 中的封装方法。

## 五、Cookie 操作

### 5.1 获取所有 Cookie

```python
cookies = wd.get_cookies()
for cookie in cookies:
    print(cookie['name'], '=', cookie['value'])
```

### 5.2 获取指定 Cookie

```python
cookie = wd.get_cookie('session_id')
print(cookie)
```

### 5.3 添加 Cookie

```python
# 典型场景：跳过登录，直接注入登录后的 Cookie
wd.get('https://www.example.com')  # 必须先打开同域页面
wd.add_cookie({
    'name': 'token',
    'value': 'abc123',
    'domain': '.example.com',
    'path': '/'
})
wd.refresh()  # 刷新后 Cookie 生效
```

### 5.4 删除 Cookie

```python
# 删除指定 Cookie
wd.delete_cookie('token')

# 删除所有 Cookie
wd.delete_all_cookies()
```

## 六、关闭浏览器

```python
# 关闭当前窗口（多窗口时只关一个）
wd.close()

# 关闭浏览器并退出驱动进程（推荐）
wd.quit()
```

> [!warning] close vs quit
>
> - `close()` 只关闭当前窗口，驱动进程仍在运行
> - `quit()` 关闭所有窗口并退出驱动进程，**测试结束必须调用 `quit()`**，否则会有残留进程占用资源

## 七、综合示例：百度搜索并获取结果

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
import time

wd = webdriver.Chrome()
wd.maximize_window()
wd.implicitly_wait(5)  # 隐式等待，见 [[05-等待机制]]
wd.get('https://www.baidu.com')

# 输入并搜索
wd.find_element(By.ID, 'kw').send_keys('Selenium Python')
wd.find_element(By.ID, 'su').click()

# 等待结果加载
time.sleep(2)

# 获取搜索结果标题
results = wd.find_elements(By.CSS_SELECTOR, '.result h3')
for i, r in enumerate(results[:5], 1):
    print(f'{i}. {r.text}')

print('当前 URL:', wd.current_url)
print('页面标题:', wd.title)

wd.quit()
```
