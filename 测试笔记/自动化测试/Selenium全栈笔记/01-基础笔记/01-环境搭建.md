# Selenium 环境搭建

> [!info] 本节目标
> 理解 Selenium 工作原理，完成 Python + Selenium + 浏览器驱动的完整环境搭建，跑通第一个自动化脚本。

相关笔记：[[02-浏览器驱动]]、[[03-元素定位八大方式]]、[[04-基础操作]]

## 一、Selenium 是什么

Selenium 是目前主流的 **Web 浏览器自动化方案**。通过它，我们可以写出自动化程序，像人一样在浏览器里操作 Web 界面：点击按钮、输入文字、获取页面信息等。

Selenium 的核心组成：

| 组件 | 说明 |
| --- | --- |
| **客户端库（Client Library）** | Selenium 官方提供，支持 Java / Python / JavaScript / Ruby / C# 等语言 |
| **浏览器驱动（Driver）** | 浏览器厂商提供，如 ChromeDriver、EdgeDriver、GeckoDriver |
| **浏览器（Browser）** | Chrome / Edge / Firefox / Safari 等 |

## 二、自动化执行原理

```text
自动化程序  ──调用──▶  Selenium客户端库
                          │
                   (HTTP请求)
                          ▼
                    浏览器驱动(Driver)
                          │
                   (转发命令)
                          ▼
                       浏览器
                          │
                   (执行结果回传)
                          ▼
                    自动化程序拿到结果
```

**执行流程总结**：

1. 自动化程序调用 Selenium 客户端库函数（如点击按钮）
2. 客户端库发送 Selenium 命令给浏览器驱动
3. 浏览器驱动驱动浏览器执行命令
4. 浏览器执行命令
5. 浏览器驱动获取执行结果，返回给自动化程序
6. 自动化程序对返回结果进行处理

## 三、安装 Python 客户端库

对应 Python 语言，Selenium 客户端库安装非常简单，用 `pip` 命令即可。

### 3.1 基本安装

```bash
pip install selenium
```

### 3.2 使用国内镜像源加速

如果安装较慢，可以指定使用国内的清华大学源：

```bash
pip install selenium -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3.3 指定版本安装（生产推荐固定版本）

```bash
pip install selenium==4.21.0
```

> [!tip] 版本说明
> 本套笔记基于 **Selenium 4.x**。Selenium 4 与 3 在 API 上有差异（如 `find_element_by_*` 系列方法已废弃，统一使用 `find_element(By.XXX, ...)`），请务必使用 4.x。

### 3.4 验证安装

```python
import selenium
print(selenium.__version__)  # 应输出 4.x.x
```

### 5.2 关闭 chromedriver 日志

缺省情况下 chromedriver 会在屏幕输出大量日志，可以这样关闭：

```python
from selenium import webdriver

# 加上参数，禁止 chromedriver 日志写屏
options = webdriver.ChromeOptions()
options.add_experimental_option('excludeSwitches', ['enable-logging'])

# 这里指定 options 参数
wd = webdriver.Chrome(options=options)
```

Edge 浏览器同理（注意类名是 `EdgeOptions`）：

```python
options = webdriver.EdgeOptions()
options.add_experimental_option('excludeSwitches', ['enable-logging'])
wd = webdriver.Edge(options=options)
```

## 六、常见问题

### 6.1 浏览器首页显示防病毒重置设置

有的电脑 Selenium 自动化时浏览器显示防病毒提示，解决方法：

- 命令行输入 `regedit`，运行注册表编辑器
- 找到 `HKEY_CURRENT_USER\Software\Google\Chrome`
- 删除其下的 `TriggeredReset` 子项
- 关闭注册表编辑器

### 6.2 闪退问题

程序运行完浏览器立刻关闭，加入 `input('按回车退出')` 等待用户输入即可。

## 七、Selenium 4 主要变化速览

| Selenium 3 写法（已废弃） | Selenium 4 写法 |
| --- | --- |
| `find_element_by_id('kw')` | `find_element(By.ID, 'kw')` |
| `find_element_by_xpath('...')` | `find_element(By.XPATH, '...')` |
| `find_elements_by_class_name('x')` | `find_elements(By.CLASS_NAME, 'x')` |
| `driver.execute_script` 仍可用 | 同上，无变化 |

详细定位方式见 [[03-元素定位八大方式]]。
