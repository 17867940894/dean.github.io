# 元素定位八大方式

> [!info] 本节目标
> 掌握 Selenium 4 中 `find_element` / `find_elements` 的 8 种定位策略，理解 CSS 选择器与 XPath 的核心写法，能应对绝大多数页面元素定位场景。

相关笔记：[[04-基础操作]]、[[03-元素定位八大方式#3.8 XPATH 定位（最灵活）]]、[[4. css表达式-上篇]]

## 一、定位方法总览

Selenium 4 中，所有定位都通过 `By` 类完成。需要先导入：

```python
from selenium.webdriver.common.by import By
```

八大定位方式对照表：

| 定位方式 | By 常量 | 适用场景 | 示例 |
| --- | --- | --- | --- |
| ID 定位 | `By.ID` | 元素有唯一 id | `find_element(By.ID, 'kw')` |
| NAME 定位 | `By.NAME` | 表单元素 name 属性 | `find_element(By.NAME, 'wd')` |
| CLASS_NAME 定位 | `By.CLASS_NAME` | class 属性（单个类名） | `find_element(By.CLASS_NAME, 's_ipt')` |
| TAG_NAME 定位 | `By.TAG_NAME` | 标签名 | `find_element(By.TAG_NAME, 'input')` |
| LINK_TEXT 定位 | `By.LINK_TEXT` | 链接完整文本 | `find_element(By.LINK_TEXT, '新闻')` |
| PARTIAL_LINK_TEXT 定位 | `By.PARTIAL_LINK_TEXT` | 链接部分文本 | `find_element(By.PARTIAL_LINK_TEXT, '新')` |
| CSS 选择器 | `By.CSS_SELECTOR` | 通用、最推荐 | `find_element(By.CSS_SELECTOR, '#kw')` |
| XPATH 定位 | `By.XPATH` | 通用、最灵活 | `find_element(By.XPATH, '//input[@id="kw"]')` |

## 二、`find_element` vs `find_elements`

```python
# find_element：找到第一个匹配的元素，找不到抛 NoSuchElementException
element = wd.find_element(By.ID, 'kw')

# find_elements：找到所有匹配的元素，返回列表，找不到返回空列表 []
elements = wd.find_elements(By.CLASS_NAME, 'item')
```

> [!warning] Selenium 4 废弃写法
> `find_element_by_id()`、`find_element_by_xpath()` 等系列方法在 Selenium 4 中已废弃，请统一使用 `find_element(By.XXX, ...)`。

## 三、八大方式详解

### 3.1 ID 定位（最推荐）

HTML 中 `id` 是唯一的，定位最稳定、速度最快。

```python
# HTML: <input id="kw" name="wd" class="s_ipt" type="text" />
element = wd.find_element(By.ID, 'kw')
```

### 3.2 NAME 定位

常用于表单元素。

```python
# HTML: <input name="wd" type="text" />
element = wd.find_element(By.NAME, 'wd')
```

### 3.3 CLASS_NAME 定位

> [!warning] 注意
> `By.CLASS_NAME` 只能传 **单个类名**，不能传 `class="a b c"` 这种复合类。如需多类名，请用 CSS 选择器。

```python
# HTML: <input class="s_ipt" />
element = wd.find_element(By.CLASS_NAME, 's_ipt')

# 错误写法（会报错）：
# wd.find_element(By.CLASS_NAME, 's_ipt bg')

# 正确写法：用 CSS 选择器处理多类名
element = wd.find_element(By.CSS_SELECTOR, '.s_ipt.bg')
```

### 3.4 TAG_NAME 定位

按 HTML 标签名定位，通常配合 `find_elements` 使用（因为同名标签很多）。

```python
# 获取页面所有 input 标签
inputs = wd.find_elements(By.TAG_NAME, 'input')
print(len(inputs))
```

### 3.5 LINK_TEXT 定位（链接完整文本）

仅适用于 `<a>` 标签，要求文本完全匹配。

```python
# HTML: <a href="...">新闻</a>
element = wd.find_element(By.LINK_TEXT, '新闻')
```

### 3.6 PARTIAL_LINK_TEXT 定位（链接部分文本）

模糊匹配链接文本，适合长链接文本。

```python
# HTML: <a href="...">这是一个很长的链接文本</a>
element = wd.find_element(By.PARTIAL_LINK_TEXT, '很长的')
```

### 3.7 CSS 选择器定位（强烈推荐）

CSS 选择器语法简洁、性能好、浏览器原生支持，是 **最推荐** 的定位方式。

```python
# 通过 id
wd.find_element(By.CSS_SELECTOR, '#kw')

# 通过 class
wd.find_element(By.CSS_SELECTOR, '.s_ipt')

# 通过标签 + class
wd.find_element(By.CSS_SELECTOR, 'input.s_ipt')

# 通过属性
wd.find_element(By.CSS_SELECTOR, 'input[type="text"]')

# 通过后代选择器
wd.find_element(By.CSS_SELECTOR, 'div#form input#kw')

# 通过子元素选择器
wd.find_element(By.CSS_SELECTOR, 'ul > li:first-child')

# 组合多个 class
wd.find_element(By.CSS_SELECTOR, '.s_ipt.bg')
```

更多 CSS 选择器语法见 [[4. css表达式-上篇]] 和 [[5. css表达式-下篇]]。

### 3.8 XPATH 定位（最灵活）

XPath 功能最强大，能定位 CSS 无法处理的场景（如基于父节点、文本内容定位）。

```python
# 通过属性
wd.find_element(By.XPATH, '//input[@id="kw"]')

# 通过文本内容（仅 <a> 等有文本的标签）
wd.find_element(By.XPATH, '//a[text()="新闻"]')

# 通过包含文本
wd.find_element(By.XPATH, '//a[contains(text(),"新")]')

# 通过多个属性
wd.find_element(By.XPATH, '//input[@id="kw" and @name="wd"]')

# 通过父节点
wd.find_element(By.XPATH, '//div[@id="form"]//input[@id="kw"]')

# 层级定位（绝对路径，不推荐）
wd.find_element(By.XPATH, '/html/body/div[1]/form/input[1]')
```

详细 XPath 语法见 [[9. Xpath选择器]]。

## 四、如何选择定位方式

> [!tip] 选择优先级（推荐顺序）
>
> 1. **ID**（最稳定、最快）
> 2. **CSS 选择器**（语法灵活、性能好）
> 3. **XPath**（最强大，处理复杂场景）
> 4. NAME / CLASS_NAME（表单场景）
> 5. LINK_TEXT / PARTIAL_LINK_TEXT（仅链接）
> 6. TAG_NAME（配合 `find_elements`）

## 五、F12 开发者工具辅助定位

### 5.1 在浏览器中验证定位

1. F12 打开开发者工具
2. 在 Console 中输入：
   - CSS 验证：`document.querySelectorAll('#kw')`
   - XPath 鉤证：`$x('//input[@id="kw"]')`
3. 确认能选到目标元素后，再写入代码

### 5.2 Elements 面板复制选择器

右键元素 → Copy → Copy selector（CSS）/ Copy XPath。

> [!warning] 谨慎使用自动复制
> 浏览器自动复制的 XPath/CSS 往往是绝对路径（如 `/html/body/div[1]/...`），页面结构稍微变化就会失效。**生产代码应手写相对路径**。

## 六、定位不到元素的常见原因

1. **元素在 iframe 中** —— 需要先 `wd.switch_to.frame()`，详见 [[06-弹窗iframe窗口切换]]
2. **元素未加载完成** —— 需要等待，详见 [[05-等待机制]]
3. **新窗口中** —— 需要切换窗口句柄
4. **元素被遮挡 / 不可见** —— 检查元素是否 `display:none`
5. **定位方式写错** —— F12 控制台先验证
6. **页面动态变化** —— 改用更稳定的定位属性

## 七、实战示例：ecsshop系统

```python
from selenium import webdriver
from selenium.webdriver.chrome.service import Service
from selenium.webdriver.common.by import By
from webdriver_manager.chrome import ChromeDriverManager
from time import sleep

service = Service(ChromeDriverManager().install())
driver = webdriver.Chrome(service=service)
driver.implicitly_wait(10)
driver.get("http://127.0.0.1/index.php")

ecs_login_image = driver.find_element(By.XPATH, "/html/body/div[1]/div[2]/ul/li[1]/font/a[1]/img")
ecs_login_image.click()

ecs_login_username = driver.find_element(By.CSS_SELECTOR, ".usBox_1 > form:nth-child(2) > table:nth-child(1) > tbody:nth-child(1) > tr:nth-child(1) > td:nth-child(2) > input:nth-child(1)")
ecs_login_username.send_keys("admin")
ecs_login_password = driver.find_element(By.CSS_SELECTOR, ".usBox_1 > form:nth-child(2) > table:nth-child(1) > tbody:nth-child(1) > tr:nth-child(2) > td:nth-child(2) > input:nth-child(1)")
sleep(1)
ecs_login_password.send_keys("123456")
sleep(1)
ecs_login_button = driver.find_element(By.CLASS_NAME, "us_Submit")
ecs_login_button.click()
sleep(3)
driver.quit()
```
