> [!info] 本节目标
> 掌握 `ActionChains` 鼠标操作（悬停、双击、右键、拖拽）和 `Keys` 键盘操作（回车、组合键、特殊键）的使用方法。

## 一、鼠标操作 ActionChains

### 1.1 导入与基本用法

```python
from selenium.webdriver import ActionChains

# 创建 ActionChains 对象
actions = ActionChains(wd)

# 链式调用：先动作，最后 perform() 才会真正执行
actions.move_to_element(element).click().perform()
```

> [!warning] 关键：必须 perform()
> `ActionChains` 的方法只是"录制"动作，**只有调用 `perform()` 后才会真正执行**到浏览器上。

### 1.2 常用鼠标方法

| 方法 | 作用 |
| --- | --- |
| `click(element=None)` | 单击（可选指定元素） |
| `context_click(element=None)` | 右键单击 |
| `double_click(element=None)` | 双击 |
| `move_to_element(element)` | 鼠标悬停到元素上 |
| `move_by_offset(x, y)` | 鼠标移动相对偏移 |
| `drag_and_drop(source, target)` | 拖拽：从 source 拖到 target |
| `drag_and_drop_by_offset(source, x, y)` | 拖拽：相对偏移 |
| `click_and_hold(element=None)` | 按下鼠标左键不松开 |
| `release(element=None)` | 释放鼠标 |
| `perform()` | **执行所有录制的动作** |

### 1.3 鼠标悬停（hover）

很多下拉菜单需要鼠标悬停才会显示子菜单。

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver import ActionChains

wd = webdriver.Chrome()
wd.get('https://www.example.com')
wd.maximize_window()

# 定位需要悬停的菜单
menu = wd.find_element(By.CSS_SELECTOR, '.nav .menu-item')

# 悬停并点击子菜单
actions = ActionChains(wd)
actions.move_to_element(menu).perform()

# 悬停后子菜单出现，再点击
wd.find_element(By.LINK_TEXT, '设置').click()
```

### 1.4 双击

```python
element = wd.find_element(By.ID, 'double-click-target')
ActionChains(wd).double_click(element).perform()
```

### 1.5 右键

```python
element = wd.find_element(By.ID, 'right-click-target')
ActionChains(wd).context_click(element).perform()
```

### 1.6 拖拽

```python
source = wd.find_element(By.ID, 'drag-source')
target = wd.find_element(By.ID, 'drag-target')

# 方式 1：拖到目标元素
ActionChains(wd).drag_and_drop(source, target).perform()

# 方式 2：拖到相对偏移（向右 100，向下 50）
ActionChains(wd).drag_and_drop_by_offset(source, 100, 50).perform()
```

### 1.7 链式组合动作

```python
# 按住元素 → 移动 → 释放（自定义拖拽轨迹）
source = wd.find_element(By.ID, 'slider')
ActionChains(wd).click_and_hold(source).move_by_offset(200, 0).release().perform()
```

## 二、键盘操作 Keys

### 2.1 导入

```python
from selenium.webdriver.common.keys import Keys
```

### 2.2 常用 Keys

| Keys 常量 | 对应按键 |
| --- | --- |
| `Keys.ENTER` | 回车 |
| `Keys.RETURN` | 回车（小键盘） |
| `Keys.TAB` | Tab |
| `Keys.ESCAPE` | Esc |
| `Keys.SPACE` | 空格 |
| `Keys.BACK_SPACE` | Backspace |
| `Keys.DELETE` | Delete |
| `Keys.CONTROL` / `Keys.CTRL` | Ctrl |
| `Keys.SHIFT` | Shift |
| `Keys.ALT` | Alt |
| `Keys.ARROW_UP` / `DOWN` / `LEFT` / `RIGHT` | 方向键 |
| `Keys.F1` ~ `Keys.F12` | 功能键 |
| `Keys.CONTROL, 'a'` | Ctrl+A 全选 |

### 2.3 基本键盘输入

```python
from selenium.webdriver.common.keys import Keys

kw = wd.find_element(By.ID, 'kw')
kw.send_keys('Selenium')

# 输入完后按回车（等价于点搜索按钮）
kw.send_keys(Keys.ENTER)
```

### 2.4 组合键

```python
# Ctrl + A 全选
kw.send_keys(Keys.CONTROL, 'a')

# Ctrl + C 复制
kw.send_keys(Keys.CONTROL, 'c')

# Ctrl + V 粘贴
kw.send_keys(Keys.CONTROL, 'v')

# Ctrl + X 剪切
kw.send_keys(Keys.CONTROL, 'x')
```

> [!note] Mac 上的组合键
> Mac 上用 `Keys.COMMAND` 代替 `Keys.CONTROL`：
> ```python
> kw.send_keys(Keys.COMMAND, 'a')  # Mac 全选
> ```

### 2.5 删除与清空

```python
# 删除最后一个字符
kw.send_keys(Keys.BACK_SPACE)

# 删除多个字符
for _ in range(5):
    kw.send_keys(Keys.BACK_SPACE)
```

### 2.6 用 ActionChains 执行键盘操作

```python
# 给焦点元素发按键（不需要先定位元素）
ActionChains(wd).send_keys(Keys.ESCAPE).perform()

# 给指定元素发按键
element = wd.find_element(By.ID, 'kw')
ActionChains(wd).send_keys_to_element(element, 'hello').perform()
```

## 三、综合示例

### 3.1 模拟拖拽滑块

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver import ActionChains
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

wd = webdriver.Chrome()
wd.get('https://www.example.com/slider-demo')

# 等待滑块出现
slider = WebDriverWait(wd, 10).until(
    EC.element_to_be_clickable((By.CSS_SELECTOR, '.slider-btn'))
)

# 按住滑块 → 缓慢移动 → 释放
actions = ActionChains(wd)
actions.click_and_hold(slider)

# 分段移动，模拟人手拖动（避免被检测为机器人）
for x in [50, 50, 50, 50]:
    actions.move_by_offset(x, 0)

actions.release().perform()
```

> [!tip] 滑块验证码
> 滑块验证码的完整处理见 [[07-滑块验证码处理]]。

### 3.2 文本框输入 + 组合键操作

```python
from selenium.webdriver.common.keys import Keys

textarea = wd.find_element(By.ID, 'content')
textarea.send_keys('Hello World')

# 全选
textarea.send_keys(Keys.CONTROL, 'a')

# 复制
textarea.send_keys(Keys.CONTROL, 'c')

# 移到末尾
textarea.send_keys(Keys.ARROW_DOWN)

# 换行
textarea.send_keys(Keys.ENTER)

# 粘贴
textarea.send_keys(Keys.CONTROL, 'v')

# 退格删除
textarea.send_keys(Keys.BACK_SPACE)
```

## 四、常见坑

### 4.1 `perform()` 忘记调用

```python
# 错误：动作不会执行
ActionChains(wd).move_to_element(menu)

# 正确：最后必须 perform()
ActionChains(wd).move_to_element(menu).perform()
```

### 4.2 悬停后子元素消失太快

子菜单在鼠标移开后会立刻消失，导致 `find_element` 时已经找不到了。解决：用 `move_to_element` 悬停后 **立刻** 在同一个 ActionChains 链中点击子元素。

```python
# 一步到位：悬停父菜单 → 移到子菜单 → 点击
ActionChains(wd).move_to_element(parent_menu) \
    .move_to_element(sub_menu) \
    .click(sub_menu) \
    .perform()
```

### 4.3 拖拽失败

某些网站的拖拽用了 HTML5 Drag API，`drag_and_drop` 不生效。解决：用 `click_and_hold` + `move_by_offset` + `release` 模拟。
