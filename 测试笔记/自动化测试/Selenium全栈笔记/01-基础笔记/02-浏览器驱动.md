# 浏览器驱动

> [!info] 本节目标
> 掌握 Chrome / Edge / Firefox 三大浏览器驱动的自动安装与手动安装方法，理解版本匹配原则。

相关笔记：[[01-环境搭建]]、[[03-元素定位八大方式]]

## 一、驱动与浏览器的版本匹配原则

> [!warning] 核心原则
> **浏览器和驱动的大版本号一定要匹配，小版本号尽量接近即可，不一定需要完全一致。**

例如 Chrome 浏览器版本是 `120.0.6099.130`，那么 ChromeDriver 选 `120.x.x` 系列任一版本都可以。

## 二、Selenium Manager 自动安装（推荐）

新版 Python Selenium 客户端库内置了 `selenium manager` 工具，运行 Selenium 程序时，它可以帮我们 **自动下载浏览器和浏览器驱动**。

### 2.1 Edge 驱动自动安装

Windows 上 Edge 缺省就有，环境搭建最简单：

```python
from selenium import webdriver

wd = webdriver.Edge()  # Selenium Manager 自动下载驱动
wd.get('https://www.byhy.net')
input('按回车退出')
```

### 2.2 Chrome 驱动自动安装

```python
from selenium import webdriver

wd = webdriver.Chrome()  # 自动下载驱动
wd.get('https://www.byhy.net')
input('按回车退出')
```

### 2.3 驱动缓存位置

Selenium Manager 下载的驱动在本机的默认路径：

```bash
# Windows
C:\Users\用户名\.cache\selenium\msedgedriver\win64\版本号\msedgedriver.exe
C:\Users\用户名\.cache\selenium\chromedriver\win64\版本号\chromedriver.exe

# Mac
/Users/用户名/.cache/selenium/msedgedriver/mac-arm64/版本号/msedgedriver
```

## 三、国内网络环境特殊处理

### 3.1 问题根源

`selenium-manager` 对 Chrome 驱动，会去网址
`https://googlechromelabs.github.io/chrome-for-testing/known-good-versions-with-downloads.json`
查询各版本驱动下载地址。这个网址在国内不同网络环境下，可能无法访问或速度很慢。

### 3.2 通过环境变量指定镜像源

`selenium-manager` 可以通过设置环境变量 `SE_DRIVER_MIRROR_URL` 指定驱动源的 URL。

**命令行设置**：

```bash
# Windows
set SE_DRIVER_MIRROR_URL=https://cdn.npmmirror.com/binaries/chrome-for-testing

# Mac / Linux
export SE_DRIVER_MIRROR_URL=https://cdn.npmmirror.com/binaries/chrome-for-testing
```

**代码内设置**（推荐，写在最前面）：

```python
import os
# 指定 Chrome Driver 下载源为阿里源
os.environ['SE_DRIVER_MIRROR_URL'] = 'https://cdn.npmmirror.com/binaries/chrome-for-testing'

from selenium import webdriver
wd = webdriver.Chrome()
```

> [!note] 仍可能有问题
> 镜像同步文件中包含的下载地址仍是 `storage.googleapis.com` 域名，单纯同步文件不会替换内部 URL。如果仍有问题，使用下面的 **手动下载** 方法。

## 四、手动下载浏览器驱动

### 4.1 Chrome 驱动手动下载

1. 打开 [Chrome driver 国内镜像地址](https://registry.npmmirror.com/binary.html?path=chrome-for-testing/)
2. 查看 Chrome 浏览器版本，选择对应大版本的驱动
3. 下载对应平台的 `chromedriver`

### 4.2 方式一：放入 PATH 环境变量

把 `chromedriver.exe` 放到环境变量 `PATH` 指定的其中一个目录里，代码无需做任何修改。Selenium 会优先在 `PATH` 路径里找浏览器驱动。

### 4.3 方式二：代码中指定驱动路径

```python
from selenium import webdriver
from selenium.webdriver.chrome.service import Service

# 指定驱动路径
wd = webdriver.Chrome(service=Service(r'd:\tools\chromedriver.exe'))

wd.get('https://www.byhy.net')
input('按回车退出')
```

### 4.4 Edge 驱动手动下载

Edge 驱动下载地址：<https://developer.microsoft.com/microsoft-edge/tools/webdriver/>

同样可以放入 `PATH` 或在代码中指定：

```python
from selenium import webdriver
from selenium.webdriver.edge.service import Service

wd = webdriver.Edge(service=Service(r'd:\tools\msedgedriver.exe'))
```

### 4.5 Firefox 驱动手动下载

Firefox 驱动（GeckoDriver）下载地址：<https://github.com/mozilla/geckodriver/releases>

```python
from selenium import webdriver
from selenium.webdriver.firefox.service import Service

wd = webdriver.Firefox(service=Service(r'd:\tools\geckodriver.exe'))
```

## 五、手动下载的弊病

手动下载 Chrome 驱动的主要弊病：**浏览器自动升级时，可能现有驱动和其不匹配，需要重新手动下载**。否则 selenium manager 还会尝试下载对应版本的新驱动，若下载不成功，自动化就会失败。

> [!tip] 最佳实践
> 生产环境推荐使用 **固定版本的浏览器（关闭自动更新）+ 手动指定驱动路径**，避免因浏览器自动升级导致的驱动不匹配问题。详见 [[03-多浏览器兼容]]。

## 六、查看浏览器版本

- **Chrome**：地址栏输入 `chrome://version/`
- **Edge**：地址栏输入 `edge://version/`
- **Firefox**：菜单 → 帮助 → 关于 Firefox

## 七、Headless 无头模式

服务器环境无图形界面时，使用无头模式运行：

```python
from selenium import webdriver

options = webdriver.ChromeOptions()
options.add_argument('--headless=new')  # Selenium 4 推荐写法
options.add_argument('--disable-gpu')
options.add_argument('--no-sandbox')

wd = webdriver.Chrome(options=options)
wd.get('https://www.byhy.net')
print(wd.title)
wd.quit()
```
