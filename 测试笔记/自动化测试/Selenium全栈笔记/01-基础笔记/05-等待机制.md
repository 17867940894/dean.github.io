# 等待机制

> [!info] 本节目标
> 彻底搞懂 Selenium 三种等待方式（强制、隐式、显式）的原理、区别与使用场景，掌握显式等待的标准写法。

相关笔记：[[04-基础操作]]、[[01-显式等待封装]]、[[10-异常捕获]]

## 一、为什么需要等待

现代 Web 应用大量使用 AJAX 动态加载，元素并非页面打开后立即出现。如果代码执行速度比页面渲染快，就会抛出 `NoSuchElementException`。

> [!warning] 永远不要假设元素会立即出现
> 生产级自动化脚本 **必须** 包含合理的等待机制。

## 二、三种等待方式对比

| 方式 | 原理 | 优点 | 缺点 | 适用场景 |
| --- | --- | --- | --- | --- |
| **强制等待** `time.sleep(n)` | 固定阻塞 n 秒 | 简单 | 浪费时间、不确定元素是否出现 | 调试、临时验证 |
| **隐式等待** `implicitly_wait(n)` | 全局轮询，找到元素就继续，超时抛异常 | 一次设置全局生效 | 不能等特定条件（如可点击） | 简单场景兜底 |
| **显式等待** `WebDriverWait` | 针对特定元素等特定条件 | 灵活、精准、性能好 | 代码稍多 | **生产推荐** |

## 三、强制等待 `time.sleep()`

```python
import time
from selenium import webdriver
from selenium.webdriver.common.by import By

wd = webdriver.Chrome()
wd.get('https://www.baidu.com')

wd.find_element(By.ID, 'kw').send_keys('Selenium')

time.sleep(3)  # 固定等 3 秒，无论元素是否出现

wd.find_element(By.ID, 'su').click()
wd.quit()
```

> [!danger] 不推荐生产使用
> `time.sleep()` 会盲目浪费时间：元素已出现仍会等满；元素没出现时 n 秒后照样报错。仅用于调试。

## 四、隐式等待 `implicitly_wait()`

### 4.1 基本用法

```python
from selenium import webdriver
from selenium.webdriver.common.by import By

wd = webdriver.Chrome()
# 设置全局隐式等待，单位秒
wd.implicitly_wait(10)

wd.get('https://www.baidu.com')

# 如果元素没立即出现，Selenium 会每 0.5 秒重试一次
# 最多等 10 秒，10 秒内出现就立即继续；超过 10 秒抛 NoSuchElementException
wd.find_element(By.ID, 'kw').send_keys('Selenium')
wd.find_element(By.ID, 'su').click()

wd.quit()
```

### 4.2 隐式等待的特点

- **全局生效**：设置一次，对所有 `find_element` / `find_elements` 都生效
- **智能轮询**：找到元素立即继续，不会等满设定时间
- **只判断元素是否在 DOM 中**：不判断元素是否可点击、可见、有值

> [!warning] 隐式等待的局限
> 隐式等待 **只等元素出现在 DOM 中**，不能等元素"可点击""可见""有特定文本"等条件。如果元素在 DOM 中但被遮挡不可点，隐式等待不会帮你等。

### 4.3 隐式等待的坑

```python
# 设置后再次调用会覆盖之前的值
wd.implicitly_wait(10)
wd.implicitly_wait(5)  # 现在是 5 秒，不是 15 秒

# 不要和显式等待混用（Selenium 官方明确警告）
# 混用会导致等待时间不可预期
```

> [!danger] 隐式等待与显式等待不要混用
> Selenium 官方文档明确警告：混用隐式等待和显式等待会导致等待时间不可预测。**项目里应二选一**。生产推荐 **显式等待**。

## 五、显式等待 `WebDriverWait`（生产推荐）

### 5.1 基本语法

```python
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC
from selenium.webdriver.common.by import By

wd = webdriver.Chrome()
wd.get('https://www.baidu.com')

# WebDriverWait(driver, 超时秒数, 轮询间隔秒数=0.5)
# until(method, message='')：直到条件为 True
element = WebDriverWait(wd, 10).until(
    EC.presence_of_element_located((By.ID, 'kw'))
)

element.send_keys('Selenium')
wd.find_element(By.ID, 'su').click()

wd.quit()
```

### 5.2 `expected_conditions` 常用条件

| 方法 | 等待条件 | 返回 |
| --- | --- | --- |
| `presence_of_element_located(locator)` | 元素出现在 DOM 中（不一定可见） | WebElement |
| `visibility_of_element_located(locator)` | 元素可见（display 不为 none） | WebElement |
| `element_to_be_clickable(locator)` | 元素可点击（可见且 enabled） | WebElement |
| `title_contains(text)` | 页面标题包含指定文本 | bool |
| `title_is(text)` | 页面标题等于指定文本 | bool |
| `url_contains(text)` | URL 包含指定文本 | bool |
| `url_to_be(url)` | URL 等于指定值 | bool |
| `alert_is_present()` | 出现弹窗 | Alert 对象 |
| `frame_to_be_available_and_switch_to_it(locator)` | iframe 可用并切换 | bool |
| `text_to_be_present_in_element(locator, text)` | 元素中包含指定文本 | bool |
| `element_located_to_be_selected(locator)` | 元素被选中 | bool |
| `new_window_is_opened(current_handles)` | 打开了新窗口 | bool |
| `staleness_of(element)` | 元素已从 DOM 移除 | bool |

### 5.3 locator 必须是元组

```python
# 正确：locator 是元组 (By.XXX, '值')
EC.presence_of_element_located((By.ID, 'kw'))

# 错误：写成两个参数
# EC.presence_of_element_located(By.ID, 'kw')  # 报错
```

### 5.4 `until` vs `until_not`

```python
# until：条件为 True 时继续
WebDriverWait(wd, 10).until(EC.element_to_be_clickable((By.ID, 'btn')))

# until_not：条件为 False 时继续（等元素消失）
WebDriverWait(wd, 10).until_not(EC.visibility_of_element_located((By.ID, 'loading')))
```

### 5.5 自定义等待条件

```python
# 用 lambda 自定义条件
WebDriverWait(wd, 10).until(
    lambda d: d.find_element(By.ID, 'kw').get_attribute('value') != ''
)

# 用函数自定义更复杂的条件
def has_more_than_5_results(driver):
    results = driver.find_elements(By.CSS_SELECTOR, '.result')
    return len(results) > 5

WebDriverWait(wd, 10).until(has_more_than_5_results)
```

## 六、等待机制封装建议

生产项目中应封装统一的等待工具类，避免每次都写一大段。详见 [[01-显式等待封装]]。

```python
# 项目中的封装雏形（完整版见 utils/wait_helper.py）
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

class WaitHelper:
    def __init__(self, driver, timeout=10):
        self.driver = driver
        self.timeout = timeout

    def element_visible(self, locator):
        return WebDriverWait(self.driver, self.timeout).until(
            EC.visibility_of_element_located(locator)
        )

    def element_clickable(self, locator):
        return WebDriverWait(self.driver, self.timeout).until(
            EC.element_to_be_clickable(locator)
        )
```

## 七、等待策略选择建议

```
页面加载完成          → 用 page_load_strategy 或显式等待 title
元素出现并可见         → 显式等待 visibility_of_element_located
元素可点击            → 显式等待 element_to_be_clickable
弹窗出现              → 显式等待 alert_is_present
iframe 加载           → 显式等待 frame_to_be_available_and_switch_to_it
简单兜底（不推荐生产）  → 隐式等待 implicitly_wait
调试 / 临时验证        → time.sleep
```

## 八、综合示例

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

wd = webdriver.Chrome()
wd.maximize_window()
wd.get('https://www.baidu.com')

# 显式等待搜索框可见
kw = WebDriverWait(wd, 10).until(
    EC.visibility_of_element_located((By.ID, 'kw'))
)
kw.send_keys('Selenium Python')

# 显式等待按钮可点击
btn = WebDriverWait(wd, 10).until(
    EC.element_to_be_clickable((By.ID, 'su'))
)
btn.click()

# 显式等待结果出现
WebDriverWait(wd, 10).until(
    EC.presence_of_element_located((By.CSS_SELECTOR, '.result'))
)

# 等待页面标题变化
WebDriverWait(wd, 10).until(EC.title_contains('Selenium'))
print('页面标题:', wd.title)

wd.quit()
```
