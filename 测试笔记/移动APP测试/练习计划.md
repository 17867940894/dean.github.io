# 整体学习路线（4大阶段 = 直接上岗）

**阶段1**：环境+命令（你现在的阶段）

搞定：模拟器、ADB、AAPT、安装卸载、日志、权限

目标：能独立搭环境、抓问题、给开发提BUG

**阶段2**：APP功能+业务测试（必学）

搞定：页面流程、中断、弱网、推送、兼容性

目标：会测真实项目（电商/社交/工具）

**阶段3**：抓包+接口测试

搞定：[[Fiddler]]/Charles抓包、篡改、弱网模拟

目标：能测接口、定位前后端问题

**阶段4**：专项+自动化基础（加分项）

搞定：崩溃/ANR、性能、电量、流量、Appium入门

目标：简历能写“专项测试”“自动化”

## 一、环境 + ADB 命令（地基）

1. 安装模拟器 + 配置 ADB + 测试`adb devices`
2. 学会`adb install/uninstall/shell`，安装任意 APK
3. 学会`adb pull/push`导出文件、导入配置
4. 学会`aapt`看包名、权限、版本
5. 学会`input tap/swipe/text`模拟点击滑动
6. 学会`logcat`抓日志、过滤崩溃 / ANR
7. 复习：完整走一遍 “安装→运行→操作→抓日志→卸载”

## 二、功能测试 + 业务流程（核心工作）

1. APP 安装 / 升级 / 覆盖 / 降级 / 卸载测试点
2. 权限测试（允许 / 拒绝 / 关闭后重开）
3. 中断测试（来电、短信、锁屏、切后台）
4. 网络切换（WiFi/4G / 断网 / 重连）
5. 引导页、缓存、清数据、异常退出
6. 实战：测一个 APP 完整登录流程
7. 实战：测一个 APP 首页 + 列表 + 详情

## 三、抓包 + 接口测试（高薪必备）

1. 安装 Fiddler/Charles + 手机代理配置
2. 抓 APP 请求、看懂 URL / 参数 / 返回
3. 弱网模拟、超时、断网、丢包
4. 篡改请求（改参数、改金额、改页数）
5. 查看加密、token、session
6. 实战：抓登录 / 列表 / 详情接口
7. 能区分：前端 BUG / 后端 BUG

## 四、专项测试 + 自动化入门

1. 崩溃 / ANR 高级定位（tombstone）
2. 性能：CPU / 内存 / 帧率 / 电量查看
3. 兼容性：不同安卓版本 / 分辨率 / 品牌 /cpu
4. 推送测试、保活、自启动
5. Appium 环境搭建（可选）
6. Appium 元素定位 + 点击
7. 自动化：写 1 条登录用例
8. 简历整理：把所有练习写成项目经验
9. 模拟面试：能口述完整测试流程

## 每天必练的3条命令

1. 看设备

```Plain
adb devices
```

1. 装包/卸包

```Plain
adb install 包.apk
adb uninstall 包名
```

1. 抓崩溃日志

```Plain
adb logcat -d *:E | findstr/i 包名
```
