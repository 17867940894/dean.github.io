# Claude 5 世代模型的上下文工程新规则（Anthropic 官方原文精简）

> 原始来源：Anthropic 官方博客，作者 Thariq Shihipar（技术成员），2026-07-24。 原始推文：[https://x.com/trq212/status/2080710971228918066](https://x.com/trq212/status/2080710971228918066) 说明：本篇为该推文及其指向博客的精简版，为前面中文编译笔记的**一手来源**。

## 背景

- Claude Code 系统提示词为新一代模型（Claude Opus 5 / Fable 5）删减 **超过 80%**，编码评估无性能损失。

- 上下文工程（context engineering）= 系统提示词 + Skills + CLAUDE.md + 记忆 + 其他来源；跨多个请求复用，因此无法写得太具体。

- 内置命令 `claude doctor`（Claude Code 中执行 `/doctor`）可自动把 Skills 和 CLAUDE.md 调整到合适规模。

## 给 Claude 松绑（Unhobbling）

- 过去在系统提示词、CLAUDE.md、Skills 三方面都过度约束。

- 内部对话记录中常出现互相冲突的指令（如「酌情保留文档」与「禁止添加注释」并存），迫使模型在冲突间反复权衡才能决策。

- 旧约束用于规避最坏情况（如删文件），多数现已可删除，改由模型依据周边上下文与自身判断行事。

- 工具增多：过去依赖 CLAUDE.md 作记忆/信息/指引来源；现可用 memory、artifacts、skills 跨会话加载与共享上下文。

## 昔 → 今：六组范式转变

|   |   |   |
|---|---|---|
|旧做法|新做法|要点|
|给 Claude 定规则|让 Claude 自行判断|旧：「默认不写注释、绝不多行 docstring、除非要求不建文档」。新：「代码读起来要像周围代码——匹配注释密度、命名、惯用法」。特定场景（用户偏好、复杂代码）旧规则反而错。|
|给 Claude 举例子|设计好接口|示例会把模型约束在特定探索空间；应把精力放在工具/脚本/文件设计（参数如何更具表达力）。例：Todo 工具把 status 列为 pending / in_progress / completed 枚举即可提示用法；「始终只保留一项 in_progress」界定期望行为。|
|一股脑写在前面|渐进式披露|把代码评审、验证拆成独立 Skill 按需调用；部分工具「延迟加载」（先 ToolSearch 检索定义再调用，如 Task 类工具，用前不占上下文）；CLAUDE.md/SKILL.md 也应构建文件树按需加载，而非堆成中央仓库。|
|反复强调|简洁的工具描述|早期模型需重复指令、更听信窗口末尾；现可删掉重复，把使用说明放进工具描述而非系统提示词。|
|记忆写进 CLAUDE.md|自动记忆|旧流程用 `#` 快捷键写入 CLAUDE.md 持久化；现 Claude 自动保存与当前工作及用户相关的记忆。|
|简单规格文档|丰富参考材料|可引用 artifacts 生成的 HTML；用代码本身作参考（如详尽测试套件、另一代码库中待移植的函数）；评分标准（rubric）可派生 verifier agents，还原开发者在某领域的「品味」（如好 API 设计长什么样）。|

## 落地到自己的上下文

### 系统提示词

与产品语境高度绑定，告诉 Claude 身处什么产品、在做什么。对 Claude Code 基本不改；若自建 agent harness，此处值得重点投入。

### CLAUDE.md

- 轻量：简要说明仓库用途，把大部分 token 花在代码库的「坑」上（如「所有类型定义集中在一个大文件、别处没有」）。

- 避免写 Claude 看文件结构/仓库即知的事。

- 细节用渐进式披露：如多套独特验证流程，做成验证 Skill 后在 CLAUDE.md 中引用。

### Skills

- 视为轻量指南，让 Claude 按需找到信息；除非极关键领域，不过度约束。

- 长 Skill 尽量渐进式披露，拆成多文件分而治之。

- 最有价值之处：承载开发者本人/团队/产品特有的观点、知识与最佳实践。

### 参考材料

- 用 `@` 提及文件引入，供 Claude 查阅计划深层细节（规格文件、设计稿、乃至整个代码库）。

- 优先代码形式的文件（高保真、Claude 熟悉的语言）；一份 HTML 设计稿通常优于文字描述或截图。

## 行动建议

- 在系统提示词、Skills、CLAUDE.md 三者之间做一轮简化（与 Anthropic 自身做法一致）。

- 直接用 `claude doctor` 命令自动完成规模调整。
